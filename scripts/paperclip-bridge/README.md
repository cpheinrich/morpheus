# Morpheus / Paperclip linkage

Opt-in operator commands for one roadmap item to many immutable execution jobs.
Git owns the linkage and verified evidence; Paperclip owns live jobs and status.
No worker enrollment, queue, native executor or release authority lives here.

Read the [integration contract and rollout gates](../../docs/paperclip-integration.md)
before using `cli.ts`. Existing pilot workers remain paused until qualified.
