# Firebase / private Paperclip HQ prototype

Opt-in, single-company transport; not an installed or deployed HQ. The Mac initiates
outbound callable requests. Paperclip remains the scheduler and conversation authority.
Read [the contract](../../docs/paperclip-hq-transport.md) before using these modules.
`daemon.mjs` adds continuous token renewal and bounded board/agent/comment publication;
`connect.mjs` retains the single-pass operator path. Consumer installation remains explicit.

[Controlled qualification](../../docs/paperclip-hq-qualification.md) joins this to
the actual HQ facade with provider-free fixtures. Real native work requires the
separate explicit operator target; default tests never start a real provider.
