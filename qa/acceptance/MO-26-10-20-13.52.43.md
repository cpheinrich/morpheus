# Opt-in iOS runner label conjunctions

- Empty `runner-labels-json` skips its validator and retains the exact ordinary
  `runner` string for both hosted and self-hosted callers.
- Nonempty input must parse to a nonempty array of nonblank strings without
  surrounding whitespace or control characters. Labels are distinct ignoring case.
  Invalid input emits no selector and cannot start the native job via fallback.
- Canonical JSON preserves every label and its order, including literal punctuation;
  `fromJSON` passes the complete conjunction to the existing native job.
- Failed/skipped/cancelled opt-in validation blocks the native job. A skipped
  validator on the default route does not skip ordinary native work.
- Native execution identity, concurrency, test selection, complete result export,
  caller validation and artifact upload requirements retain their existing behavior.
- Focused offline checks and targeted guard mutations pass, plus required typecheck,
  compile, PM index and final-head CI. No empirical runner/cancellation/delivery credit
  is claimed, and no live dispatch or host operation is part of this source task.
