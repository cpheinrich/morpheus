# Cancelled downstream companions in a complete no-start census

## Design before implementation

A real terminal five-job run has two executed successful Ubuntu preflight jobs,
a cancelled never-assigned native job, and cancelled never-assigned Ubuntu
qualify/native upload dependents. The downstream placeholders report completion
one second before creation and exact created/start strings. Keep these timestamps;
never normalize, relabel or omit the rows.

Permit the new cancelled Ubuntu companion case only when it is completed,
`neverRan(cancelled)` proves no start, runner/group fields are explicitly null/zero
or empty, steps are empty, and the same complete census contains a successfully
executed Ubuntu preflight (positive runner, nonempty name, real completed successful
step). Existing successful Ubuntu/skipped cases stay unchanged. An executed failed
preflight, unknown executor, incomplete/foreign census or owner race still refuses.
No job-name inference, dependency, schema/config/epoch or deadline change is needed.
This is a small provider-specific predicate; use the existing classifier, no generic
package or framework.

## Required outcomes

- Actual five-row field projection, preserving raw timestamps/steps/null-zero
  states, goes through normal Controller.tick and FakeGitHub. No native tests,
  upload or receipt is fabricated. One local attempt becomes failed with truthful
  no-start census quiescence; intent becomes pending/dispatch-hosted; no repair work,
  repeated cancellation or old dispatch is created.
- The next ordinary planner reserves a NEW build and makes exactly one hosted a2.
  Verify unchanged source/debt/deadline/burned a1 reservation, and normal current
  controlRef selection separately from the a1 control. No admission nonce carries
  into its new dispatch effect.
- Refuse cancelled-companion assignment/group/start/step/malformed/foreign fields,
  missing or unverified/failed executed preflight, wrong run/head/attempt, empty or
  partial/duplicate pages, and tests/upload/new-owner races. Existing tests retain
  exact pagination, waiting/deadline and ownership protections.

The raw provider file is retained privately; public tests anonymize IDs/positive
runner names/nonce label only, and preserve all classifier-used status, timestamps,
runner null/zero/group and step-execution fields. This is source correctness only;
review/CI, coherent consumer pinning and actual-ledger qualification/adoption are
separate and held. No live cancel, dispatch, service or provider operation is part
of this task.

## Later control-only main

The regression makes a new main revision visible in the source catalog with the
same app input digest before the first recovery tick, and makes `controlRef=main`
resolve to that new revision. The old a1 run/head stays on its original control.
`failedRun` records no-start for that existing owner; the next normal
`reconcileIntent` reads current controlRef and `planAttempt` selects the existing
intent's source/app-input lineage. The test expects old source + new control for
hosted a2, not an assumed old control or manual source/lane rewrite. Both build
reservations stay burned. The new effect has no inherited admission label/nonce
argument; consumer-side scope/operational proof remains separate.
