# Host app research in project HQ

- A project can validate a study folder and identify invalid references or mismatched asset digests before publishing.
- The shared React viewer opens screen and control deep links, shows navigation and behavior annotations, and verifies lazily read screenshots and downloads.
- A narrow viewport keeps the study and signals usable with keyboard navigation, a screenshot switch, and horizontal scrolling within the rankings region.
- The ASO CLI fetches an attributed device and country snapshot for configured search terms after checking included credits, preserves the previous file on failure, and marks lookup gaps separately from unranked terms.
