# Run Factory workers across hosts

- The existing desktop tools give a delegation a stable task ID distinct from its provider session. A reply continues the task, while a new brief after completion gets a new task ID. Historical run records stay readable.
- CI exercises the adopted A2A 1.0.1 behavior, single claim under contention, stale attempt rejection, reconnect, and cancellation. Factory retains an uncertain attempt until process cleanup is verified.
- An eligible enrolled worker can claim a task using an outbound listener. The claim considers current free capacity and reserves the writable workspace and worker slot. Provider selection retains the gateway quota and explicit-model rules.
- A desktop controller can send a brief, answer a remote clarification, and open a verified artifact delivered by an enrolled host. Show real host and task identity, supervision, and artifact retrieval before closing rollout acceptance.
