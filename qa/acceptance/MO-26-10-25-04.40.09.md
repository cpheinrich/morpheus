# Paperclip Markdown closeout acceptance

- Existing exporter invocation and JSON-only records remain compatible.
- An existing canonical snapshot renders a deterministic adjacent Markdown file,
  linked to its exact JSON digest, preserving every captured field and the
  verified/unverified attachment distinction without embedding binary bytes.
- Repeats reuse exact bytes; reopened/changed records get new views; conflicting
  old JSON/Markdown/blob content refuses rather than overwriting.
- Untrusted HTML, scripts, Markdown and arbitrary backtick runs remain display
  text. Source/path misbinding, traversal, Git metadata aliases and symlinks refuse.
- Exact committed base/head objects establish a bounded append-only comparison:
  old records/blobs cannot be edited, deleted or renamed; additions have valid
  identities, hashes and canonical Markdown relationships.
- A narrow PR workflow invokes the guard. Ordinary review, PM and CI are retained.
- Focused temporary-Git tests, typecheck, compile and PM index pass. No live
  provider acquisition, upstream atomicity/completeness or authority is claimed.
