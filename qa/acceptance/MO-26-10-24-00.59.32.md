# Interactive Paperclip pool delegation

From the existing Codex desktop conversation, submit bounded work to a registered remote
worker, stream intermediate output, receive and answer a clarification, send a follow-up
into the same native provider session, and reconnect without duplicating execution. Run this
on remote Codex and remote Claude. Record exact worker, host, model/effort, issue/run/native
session identities and independently read-back nonce artifacts, not merely successful exits.

The unavailable mini Claude login is an explicit pending acceptance condition. Deterministic
Claude transport tests count as transport tests only. A caller disconnect must not duplicate
or abandon a Paperclip-owned run. Transport loss or host-service restart must either recover
the original run or prove stopped before replacement; unknown ownership refuses replacement.

Tests cover repeated submissions and uncertain creation, stale question IDs, autonomous reply
limits, permission escalation refusal, unavailable native auth/quota, cursor replay, session
and worker-binding drift, concurrent writers, cancellation and reconnect. Native follow-ups
may be queued at a provider turn boundary; report this capability plainly. Neither provider
may silently change account, model, billing path, workspace or authority.

No provider credentials in Git, prompts, command arguments or logs. No paid API/extra-usage
fallback, production project migration, simulator work or bypass of normal Git review/CI.
