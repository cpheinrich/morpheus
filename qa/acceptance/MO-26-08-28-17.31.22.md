# Acceptance — stale-installation bootstrap

- A session start with no `morpheus` binary emits the exact consent question and performs no
  installation.
- A session start with a binary that rejects the entire `self` group emits the same instruction.
- No records the schema-valid disabled device choice without invoking the stale binary.
- Yes clones reviewed current Morpheus `main`, invokes only that clone's committed CLI, installs a
  standalone global package, registers the current project, and enables managed Git hooks.
- Existing Claude/Codex SessionStart entries and unrelated Git hook content remain intact; only the
  legacy direct `context brief` entry is replaced.
- A clean post-merge test from a pre-#167 fixture reaches current Morpheus and installs both managed
  hooks without depending on any source checkout.
