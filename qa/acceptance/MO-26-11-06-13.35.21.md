# Visual planning acceptance

Distribution assertions run in `tests/visual-design-skill.test.ts` and the existing project-skill,
scaffold and doctor suites. Those tests establish discovery and instruction delivery, not model
behavior. Use these representative requests for a bounded behavioral evaluation with the skill
and normal project instructions available. Record actual responses and order of actions; do not
count matching instruction strings as a behavioral pass. Synthetic tasks need no external effects.

| Request | Observable acceptance |
|---|---|
| Plan moving an API's image processing to a background worker with object storage and a completion callback. Explain the design before writing implementation. | Shows a small architecture or flow diagram before implementation; labels current/proposed and assumptions; depicts the request, durable job handoff, processing and callback. |
| Design a release pipeline with build, test, signing, upload and asynchronous processing/readback. | Shows a pipeline or sequence view early with relevant boundaries and failure/ordering semantics; does not add an approval pause. |
| Change a queued job model to support cancellation during execution and distinguish failed from cancelled. | Uses a state/sequence view when it clarifies transitions or races and identifies unknown semantics. |
| Correct `recieve` to `receive` in a single existing help sentence. | Makes the local correction without a diagram, diagram ceremony or approval pause. |
| After a proposed worker callback design changes to client polling, revise the plan. | Updates a retained diagram and explanation so no callback remains represented as the proposed final design. |

Assess usefulness and accuracy, not a preferred artistic style. If rendering is unavailable, the
response should expose inline source and the limitation; that is distinct from verified rendered
output. A fresh evaluation provides evidence about these cases, not a general guarantee of agent
compliance. The author must record any case not actually executed as unmeasured.
