# Factory worker speed acceptance

- An operator can set the default for Codex and Claude independently of the controller's interactive settings. An explicit Standard request selects Standard.
- The default reaches both local and Fleet launchers. Existing sessions and retried submissions keep their recorded execution intent. Legacy settings and tasks that omit speed remain compatible.
- Tests verify worker launch settings, Fleet admission and authorization, and the retained gateway and permissions checks. Verify actual speed separately with fresh sessions on the authorized, enrolled routes.
- Deploy the reviewed source through the established Factory controller, supervisor, and service rollout. Inventory the active enrollments and record readiness, actual provider speed, and cleanup for each affected host or route in the private rollout record.
