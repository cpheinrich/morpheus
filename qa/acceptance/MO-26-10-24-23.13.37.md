# Scoped Morpheus CI

- A cumulative PR containing only ordinary documentation, roadmap/acceptance prose
  or worklog Markdown skips Node work, browser QA, the Claude bridge and artifact ABI.
  The required `node / check` is still reported as skipped. PM and applicable PR
  conventions run independently; existing unlabelled draft behavior is preserved.
- QA code selects browser tests; bridge code selects bridge tests; artifact core
  changes select artifact and browser trace consumers. General TypeScript selects
  Node. Shared configuration, workflows and unclassified paths select every check.
  Runbook/example/skill Markdown remains an input to Node tests.
- Comparison covers every PR commit from its merge base, handles deletions and both
  sides of renames, and treats filenames as opaque data. Missing history, malformed
  events, incomplete/oversized Git output or failed detector jobs cannot skip work.
- Main pushes run all checks. Existing reusable Node callers default to running.
- Both Python 3.9 and 3.14 execute the four filesystem/environment/fixture suites on
  one runner. A failure in one version does not suppress testing the other and still
  fails the step. The pinned Node 24 upload/download/readback runs once, retaining
  admission, exact bytes, 2 MiB envelope, one-day retention and ten-minute job cap.
- Before merge, focused tests and typecheck/build/index pass; GitHub evidence shows
  both the all-checks implementation run and an actual prose-only PR comparison,
  including required check names. Independent review and final CI pass.
