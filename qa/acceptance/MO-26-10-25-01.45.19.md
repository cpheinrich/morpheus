# Web QA composer and Markdown placement captures

- Enter saves the pin locally and clears text, selected scope, placement details and focused
  marker/row from the composer. The saved row remains editable with its original scope/image.
- Save failure preserves editable text and context with a visible storage error. Image failure
  remains visible on the saved row and in details on reselect; usable HTML remains sendable.
- Send freezes the requested text/scope before encoding. Its successful acknowledgment removes
  only unchanged submitted versions, preserving new drafts, edits and the current selection.
  A failed POST preserves the editable comment. Late capture work does not erase a newer status.
- Scrolling a styled Markdown page beyond a clipped diagram/scroller retains the correct
  viewport JPEG pixels and placement coordinates. The regression must fail when the old
  offscreen-box pruning is restored. Existing immutable images, storage, media omissions,
  bounds, fixed dialogs, nested scroll and iOS transport remain covered in both browser engines.
- Evidence comes from isolated fixtures and a read-only copy of the overview. Do not modify the
  active Paperclip QA checkout, its comments, responder, ports4610/4611 or the user's live tab.
