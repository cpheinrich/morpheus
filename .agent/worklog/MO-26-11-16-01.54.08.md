# Decide iOS PR scope before reserving a Mac runner

A controller-only Evo PR was queued for both Mac jobs even though its changes were outside the
native watch paths. The workflow checked scope only after a native checkout. The hosted check
now uses the same Git command and can skip the Mac only when it successfully proves that the
exact PR has no watched changes. Native work still checks the exact source and scope. An invalid
or unavailable hosted result falls back to the original Mac path. Manual delivery and explicit
runner-selection callers keep their existing validation.

All 260 focused workflow tests passed, including the actual Git fixtures and native job condition
matrix. The Homebrew `actionlint` binary checked the workflow, including the shared YAML anchors.
