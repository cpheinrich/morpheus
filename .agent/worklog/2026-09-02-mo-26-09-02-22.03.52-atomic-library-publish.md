# Atomic research-library publish

Added the missing first-publish path to the shared research-library CLI. It accepts descriptive
metadata for one completed Babel directory, derives both immutable artifacts without writing into
that directory, verifies create-only remote uploads, and exclusively creates the v2 catalog
manifest last. The integration test uses fake Docling and GCS executables to prove both success and
the no-manifest-on-upload-failure boundary.

One test harness attempt encoded the full GCS URI as a filename and exceeded macOS's filename
limit. Replacing that test-only key with SHA-256 preserved the intended fake-remote behavior.
