# MO-26-09-30-21.47.10 — Admit one automated release per configurable slot

PR [#309](https://github.com/cpheinrich/morpheus/pull/309). Lets Evo run its full release
pipeline every six hours (no-op when main is unchanged, deferred while recovery owns an
incident) without a second scheduler.

## What shipped

- `AdmissionConfig.slotMinutes` (optional): the local day divides into slots; `window` is
  relative to the slot start and must close before the slot ends; one automated release per
  slot. Keys and nonces append the local start time (`2026-10-01T0600`); day-long periods
  are unchanged, so no app changes behaviour until it opts in.
- Invalid sizes and overlong windows throw rather than silently becoming a day.

## Evidence

- `tests/ios-nightly-core.test.ts` 25/25 with the new slot group; `pnpm test` 56 files,
  1529 tests; `pnpm typecheck` clean; `dist/` recompiled.
- Evo adoption and the first six-hourly slots are recorded in Evo's follow-up item.
