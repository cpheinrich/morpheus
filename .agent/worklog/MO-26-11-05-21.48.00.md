# Pinned Lizard complexity toolkit

Source: the controller mandate `cto-rollout/mandate.md` (Codex visualizations, 2026-11-04 run).
Morpheus owns a reusable, pinned Lizard toolkit: installation, targeted checks on the functions an
agent changes, reviewer-packet integration and a CI backstop, merged after independent review and
CI. This item is the toolkit only; the Morpheus baseline refactor is a separate claimed item held as
a WIP PR. Modes: Evo blocks on cyclomatic complexity (CCN) > 15 once its baseline refactor merges
and warns on cognitive complexity; Lakina and Morpheus stay advisory until their baseline refactors
merge. No global hard gate, no blanket ignores, no threshold gaming; analyzer false positives need
a source-confirmed narrow classification, semantic exceptions a reviewed reason.

**Acceptance.** Toolkit merged; install, targeted check, review packet and CI path verified on a
real checkout; Evo enforce-vs-cognitive-advisory contract covered by tests; an exact minimal

## What was built

The design took a fresh independent design review before code (report kept by the controller; its
seven corrections are all applied): unsupported languages are coverage notes, not failures; the
targeted diff covers untracked files, pure deletions, renames and unusual paths with plain Git;
enforce CI measures every in-scope file; suppression comments are neutralised and warn; the pin is
fetched by commit and keyed with its wheels; advisory never fails CI; a policy change shows as a
before/after warning. CI is a step inside the required conventions job.

- `src/complexity/`: `pin.ts` (Lizard commit + hash-locked wheels, canary values), `install.ts`
  (git fetch by id, `python3 -m venv`, `pip --require-hashes --only-binary :all:`, canary on every
  status), `lizard_runner.py` (stdlib runner, same-length neutralising), `diff.ts`, `policy.ts`,
  `evaluate.ts`, `check.ts`, `format.ts`; `src/cli/complexity.ts`.
- `morpheus complexity install [--check]`, `morpheus complexity check [--base] [--all] [--json] [--ci]`.
- `review prepare` prints the real result (or NOT RUN with the reason) into the packet.
- `pr-check.yml`: "Check function complexity" after "Check PR conventions", reusing the pr-head block.
- `morpheus init`: new manifests enrol advisory; AGENTS/README tell the agent to install, check and
  report. Established manifests are not enrolled. Morpheus enrols itself advisory, excluding `dist/**`.
- Docs: `docs/runbooks/complexity.md`, architecture §7.12a, device-bootstrap and CLI runbooks, decision.

## Result

On this checkout the targeted check runs in about a second: advisory, the only over-limit function
it touches is the pre-existing `parseArgs` (CCN 21), which the Morpheus baseline refactor owns. Every
new function in this change is at CCN 15 or less. The real install works on Python 3.14 and on
macOS's `/usr/bin/python3` 3.9.6 (the declared floor).

  (`lizard_core/file_info_builder.py` `end_of_function`), and a comment containing `GENERATED CODE`
  stops analysis of the rest of the file (`lizard_core/file_analyzer.py` `comment_counter`). A
  marker inside a string literal does not trigger either; only comments do.
