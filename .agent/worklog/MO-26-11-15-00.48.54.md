# Retain Fleet artifacts on invocation deadline

A verified worker deadline returned a generic failure and omitted finished recording files. The runtime can now attest the deadline and collect explicit checkpoint files using the ordinary private transport after cleanup. A deadline remains a failed task even when partial artifacts are present.

The guardian/executor fixture terminates a standing process at the real deadline after it writes a checkpoint and an unselected file. It attests cleanup and the exact session and returns only the named artifact. Artifact tests cover the explicit file list and path boundaries. The runner test proves the task remains failed and retains the artifact names. Existing normal, cancellation, recovery and Xcode enrollment cases passed.

Independent review confirmed the deadline and publication boundary and cleared a substantive test gap on condition. The retained tests verify the real supervisor publication path, partial upload recovery, authority and cleanup refusals, and real guardian deadlines with missing or malformed manifests. All 54 focused tests passed after those additions.

The reviewer observed one intermittent failure in the unchanged output-limit test during the earlier 51-test run. Its narrow diagnostic passed, and the subsequent full focused run with the conditioned tests passed all 54 tests.
