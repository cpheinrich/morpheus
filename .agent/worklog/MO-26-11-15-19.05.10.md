# Verify single-repository Fleet source

A detached attempt fetched one shallow commit and never created an origin.
The supervisor now observes the default branch and fetches the exact source and
comparison commits with history. The worker uses the existing local comparison
remote construction, at the admitted detached HEAD. The mirror credential stays
with the supervisor. Continuation keeps the original checkout. This is Git and
Factory-specific glue using the existing helper, without another dependency.
