# Profile follow-ups: human-wait phase and strict --since

Two follow-ups the independent review of `morpheus profile` (#355) raised.

## Human waits

**What the transcripts actually record** (scanned the 1,500 most recent Claude Code transcripts on
this machine):

- `AskUserQuestion` and `ExitPlanMode` are ordinary tool calls whose result arrives when the person
  answers. They were already excluded from the busy intervals, but a wait under the five-minute
  idle cap still counted in full as active time, and the span landed in phase `other`.
- A **refused** permission prompt writes a tool result with `toolDenialKind: "user-rejected"` and
  `toolUseResult: "User rejected tool use"` (3 instances). Other `toolDenialKind` values involve no
  person: `automode-blocked` (32, the auto-mode classifier), `permission-rule` (24),
  `automode-unavailable` (2), and `interrupted` (2, where the agent was working until stopped).
- An **approved** permission prompt leaves no marker at all. Its wait is indistinguishable from
  the tool's own run time. This is a known gap and is documented in `architecture.md`.
- Codex sessions here run with `approval_policy: never`; no approval or user-input events were
  found in 652 rollouts, so Codex is unchanged.

`human-wait` is a new phase. `activeTime` takes a `waiting` interval list and removes the waited
part of each gap *before* the idle cap applies. `morpheus wait-ci` is now classified as `ci-wait`.

## --since

`sinceMs` round-trips the parsed year, month and day through `Date` and refuses any that roll
over (`2026-02-30` → March 2, `2026-13-01` → January 2027). It still returns local midnight.

## Validation

- `pnpm typecheck`, `pnpm lint`, `pnpm compile`, `pnpm morpheus pm index` passed.
- `pnpm exec vitest run tests/profile`: 114 passed. The new `tests/profile/human-wait.test.ts`
  pins active time to 52 s for a transcript that read 412 s before. It also checks the month-end
  and leap-day boundaries for `--since`. Removing either fix fails its tests: active time fails 1
  test, and dropping the date check fails 7.
- `node dist/cli/index.js profile report` on this machine's transcripts (all time) now shows
  `human-wait | 12 calls | 1h17m` that was previously spread into `other` and active time;
  `--since 2026-02-30` is refused with exit 1.
