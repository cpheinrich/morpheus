The [audit](../../docs/morpheus-context-audit.md) combines release worklogs, public
claim/PR times, pre-audit local trace and profile aggregates across four projects,
and a paired resident MCP/one-shot CLI development probe. Factory ran an independent
Fable 5.2 audit in the claimed checkout. Its first lease expired before the memo;
resuming the saved session on the pinned gateway produced a complete memo. The
controller reproduced heading-fragment and range read failures, verified a valid
read, and reproduced the profiler's worktree-path misclassification.

The first probe expected CLI citation objects but the command emits a formatted
output field; the corrected extraction used citation headers, and the corrected run
used a new clone. The secondary host's default CLI lacked context profiling; its
alternate install had the command but no context trace coverage in the sampled
checkout families. Missing data is not zero usage. Logs, worker IDs, paths and
private excerpts stay out of the branch.

Focused context and profile suites passed 154 tests against the same product code.
Typecheck, compile, PM index and PM validation are the checks for this draft.
No runtime change. The [analytics design](https://github.com/cpheinrich/morpheus/pull/715)
describes the proposed collection and next decision.
