# Paperclip pilot: host-bound execution and historical decision evaluation (source)

## What was built

Source only; the parent session owns runtime provisioning, live runs and review. `scripts/paperclip-pilot/` adds a Paperclip `codex_local` command wrapper (`worker.py`), a foreground host supervisor (`supervisor.py`), a quota helper over the existing `nativeQuota` (`quota.mjs`), an operator CLI (`pilot.mjs`) and neutral worker instructions. `qa/evals/agent-stack/` holds twelve sanitized historical cases, separate oracles, frozen baseline and candidate prompts, tagged lessons and a freeze/render/score/report harness. Focused tests: `tests/paperclip-pilot.test.ts`.

## Learned while building

- **A receipt initialized as `not-started` hid a crashed run.** Reconcile treats `not-started` as final, so a supervisor killed after launch left descendants that the next run never censused. The orphan fixture caught it; the pre-launch state is now `pending`. A placeholder state has to be the one that demands checking.
- **The entry guard `argv[1] === fileURLToPath(import.meta.url)` silently does nothing through a symlinked path.** On macOS `/var` is `/private/var`; the tamper test, run from the temp directory, exited 0 having verified nothing. Both CLIs now compare realpaths. Same family as "a verifier that cannot report looks like one that found nothing".
- **`ps axeww` output exceeds Node's default 1 MB `execFileSync` buffer** on a busy Mac; the census helper in tests needs an explicit `maxBuffer`.
- **An orphan that inherits the killed supervisor's stdout keeps the pipe open,** so Node's `close` event never fires; wait on `exit` for a SIGKILLed parent.
- **Paperclip's `PATCH /agents/:id/permissions` schema requires `canCreateAgents` and `canAssignTasks` together** (read from the installed `@paperclipai/shared` validators); a partial body is a 400. Creation accepts `permissions` directly.
- **`codex exec --json` does not name the serving model**, and Paperclip's parser does not extract one. Receipts record the request and an explicit `unknown`.
- **The private worker instructions carried a lessons paragraph.** Installed as the workspace `AGENTS.md`, it would have given the baseline the candidate's policy. The tracked asset drops it, the harness freezes it, and `stage` reports — never silently overwrites — a different existing copy.
- **Oracles needed widening before freeze** where a second action was equally right (H01, H02, H07: fixing the underlying setting). Done before any execution; recorded in the eval README.

## Dead ends

- Per-run reservation release on a wrapper's own exit alone: a SIGKILLed wrapper never releases, so the next reservation asks the host supervisor to reconcile instead.
- Reaping the model leader before signalling its group risks PGID reuse; the ownership-marker census (the `guarded-run.py` pattern) avoids depending on the group at all.

## Not done here

No model, provider, SSH mutation or PR from this session. Live acceptance (nonce artifacts, contention drill, cancellation, restart) and the evaluation runs are the parent's. The manifest is frozen for `gpt-6.1-sol`/`medium`; if the controller host needs another model, delete and refreeze it before any dispatch.
