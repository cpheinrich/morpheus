## What changed

Roadmap item files were already the canonical data. The shared README table was presentation
state regenerated by item creation, blocking, issue linking, migration, and explicit indexing.
Those write paths now leave the static roadmap README alone. Validation still reads every item,
and the lower-churn goal and request indexes remain generated. `pm index` recognizes and removes
the old marked table once, so existing projects converge instead of keeping a frozen stale table.

The initializer now scaffolds the same static README and does not add generator markers to it.
The PR check treats a roadmap README edit as documentation rather than generated bookkeeping.

## Verification

- TypeScript typecheck and production compilation passed.
- All 946 Morpheus tests passed, including regressions for creation, blocking, issue linking,
  initialization, and `pm index` leaving the roadmap README byte-for-byte unchanged.
- Darwin's `/hq/product/roadmap` parser was executed against its current content and returned all
  40 item files while excluding `README.md`; its page regression test uses that same function.
