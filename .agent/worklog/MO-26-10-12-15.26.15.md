# Review visual evidence and recover validated author reviews

The Manager runs on GitHub-hosted Linux, while Evo's iOS CI runs on Mac mini simulator VMs.
The author-first capture path uses that existing Mac build workflow and requires independent
reviewers and Manager sessions to inspect actual pixels. Missing iOS captures still escalate.

Morpheus #353 had a committed review but lacked its `agent-reviewed` label. The Manager previously
refused it without checking the record. Its apply step now calls the existing author-review checker
against the live head before recovering that label. Invalid, missing, or unreadable records remain
blocked. No package was needed; the existing checker was reused.

Focused verification: `pnpm exec vitest run tests/gh-manager.test.ts tests/gh-manager-evidence.test.ts tests/local-review.test.ts tests/init.test.ts` (279 passed), `pnpm typecheck` (passed), and `pnpm compile` (passed). These cover Manager decisions and evidence, review validation, and scaffolding.

The fresh reviewer found R01: an opted-out project's `waived` result could be mistaken for a
completed author review, allowing the Manager to add `agent-reviewed` without a record. I made
`authorRecordProblem` reject waivers and added an opt-out/no-record regression test. Focused
Manager/review tests passed 189/189 after the fix; typecheck and compile passed. The same reviewer
inspected the correction and cleared R01 on the focused follow-up.

The first full CI run found a scaffold size failure: 16,141 bytes against a 16,000-byte limit.
I shortened the new capture instruction, regenerated dist, and ran the focused scaffold tests
(88/88), typecheck and compile. The same reviewer used the final allowed turn to inspect that
late correction, verify the generated text is 15,983 bytes, and clear the final merged head.

The fresh high-risk reviewer found R01, a substantive waived-review bypass in author-label recovery. The author rejected waived results and added an opt-out/no-record regression test. After CI exposed a scaffold size limit, the author shortened the visual instruction; the same reviewer cleared both corrections in two focused follow-ups. No findings remain.
