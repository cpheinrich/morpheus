# Follow pull requests through merge

The merge runbook and scaffold now keep the author responsible for required CI,
recovery and merge verification. The blocker record names the recovery attempts
and the smallest external action that can unblock the PR. GitHub Manager remains
the backstop.

The scaffold and instruction-drift suites passed all 81 tests. Type checking,
compilation, project index generation and whitespace checks passed. Complexity
passed for the two touched functions in the instruction modules.
