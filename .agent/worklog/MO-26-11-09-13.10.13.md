# Follow pull requests through merge

The merge runbook and scaffold now keep the author responsible for required CI,
recovery and merge verification. The blocker record names the recovery attempts
and the smallest external action that can unblock the PR. GitHub Manager remains
the backstop.

The scaffold and instruction-drift suites passed all 81 tests. Type checking,
compilation, project index generation and whitespace checks passed. Complexity
passed for the two touched functions in the instruction modules.

## Independent review

Independent review found that the unfiltered CI wait could return a failure for an optional check even when every required check passed. The guidance now uses the required-check filter consistently. The reviewer cleared the change subject to that correction and verification. Type checking, 136 focused tests, compilation, complexity and whitespace checks passed.

[Node CI](https://github.com/cpheinrich/morpheus/actions/runs/42700802154/job/129444754210) found both startup budgets exceeded. The shortened guidance fits both startup budgets and preserves author responsibility for required CI, recovery and merge verification. The reviewer independently ran all 153 focused tests and cleared the correction. The poll wording note was declined because the runbook and hook carry the exact rule.
