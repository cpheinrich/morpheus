# MO-26-10-13-17.34.56 — Pin nested shared refs; let a release's Firebase tests opt out of cancellation

Issue #393, found while making darwin-health/evo's CD reliable (EV-26-10-13-16.25.34).

## Probe (2026-10-14, evidence for the shape)

Temporary workflows `probe-nested-outer.yml` / `probe-nested-inner.yml` on this branch (commit
642b7eac, removed before review) were called from a throwaway Evo branch `probe/nested-refs`
(deleted after one run), Evo run 38491138599:

- `outer` nested `./.github/workflows/probe-nested-inner.yml` by local path and the inner job ran,
  so a local reference inside a called workflow resolves in cpheinrich/morpheus at the called
  commit, not in the caller's repository (Evo has no such file).
- In both jobs `github.job_workflow_sha` and `github.job_workflow_ref` were empty;
  `github.workflow_sha` / `workflow_ref` / `repository` were the caller's (Evo). So a checkout at
  `job_workflow_sha` cannot pin actions; the consumer has to name the revision.

## Change

- `ios-nightly-build.yml`: `release-preflight.yml` and `ios-ci.yml` by local path; new
  `actions-ref` input passed through to `ios-ci.yml`.
- `ios-ci.yml`: new `actions-ref` input (default `main`); a sparse, credential-free checkout of
  cpheinrich/morpheus at that ref into `.morpheus-ci` before the first action use; `ios-simulator`
  and `swift-changed-files` used by local path from it (`swift-changed-files` reaches
  `scripts/swift-changed-files.sh` through `$GITHUB_ACTION_PATH/../../../scripts`, so `scripts` is
  in the sparse set).
- `firebase-tests.yml`: new `concurrency-key` input; groups key on it when given and
  `cancel-in-progress` is on only when it is empty.
- `tests/workflows.test.ts`: no non-comment line in any shared workflow references
  `cpheinrich/morpheus/.github/...@main`; the checkout step shape and ordering; the
  concurrency-key shape; the two cancellation tests accept the opt-out expression.
- Not changed: `src/init/templates.ts` still generates a consumer caller on `@main`, which is the
  documented starting point; pinning is the consumer's reviewed decision.
