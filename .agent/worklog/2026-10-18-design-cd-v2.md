# Design Morpheus CD pipeline V2

Christopher authorized a requirements-first CD rebuild, independent agents, repository
changes/merges and real internal TestFlight validation. This PR is the design phase;
implementation and eight consecutive delivery lineages remain required afterward.

## Evidence and work in progress

- Read Morpheus/Evo operating records and inspected actual scheduler/recovery state,
  relevant GitHub runs and incidents, Apple build/group metadata and credential status.
- Separate agents are collecting the complete RCA, primary-source research and source
  adapter inventory. Private chats and raw logs remain private; public evidence is sanitized.
- Graph CLI failed because another pre-coordination generation is active. No graph
  generation/coverage claim is made; targeted source reads were used as fallback.
- Existing Evo checkout has unrelated changes and is untouched. This task owns its
  isolated Morpheus claim/worktree.
- The WIP proposes GitHub-authoritative delivery state, deterministic reconciliation,
  bounded agents, exact internal receipts and distinct source/control identities.
- Fresh design review and empirical CAS/failure prototypes are pending. No production
  behavior has changed and no delivery success is claimed by this document.

## Validation

The WIP was deliberately opened before final design validation, as requested.
`pnpm typecheck` and `pnpm compile` passed. `morpheus pm index` passed; the source
CLI invocation through tsx was sandbox-refused at its IPC socket, so the installed
CLI performed the same index operation. No generated output changed.

`node --test qa/prototypes/cd-v2/protocol.test.mjs` passed 45/45 after the fresh
review's additional cases. Six cases use real local Git, two use owned child
processes, 34 are explicit protocol models, and three reproduce failure
counterexamples. Two isolated live GitHub contention probes each admitted one
writer and rejected three siblings; both probe branches were removed and their
absence verified. These are design evidence, not production adapter or delivery
qualification. The validation appendix records limits.

The fresh initial reviewer identified three substantive gaps: uncertain-operation
resolution, production catch-up/quarantine/ordering, and actual delivery cadence.
The design now specifies quiescence and separate Apple upload/build observations,
retained uncertainty with safe replacement decisions, explicit missed-slot policy,
age/quarantine waits, monotonic promotion and deadline/scheduled-path evidence.
Final same-reviewer assessment includes the private RCA through authorized local
access and the public executable probes. Detailed operational findings remain in
private Evo records after automatic approval review rejected public publication
of the RCA; this PR contains only an evidence-handling pointer.
The initial incomplete verdict is retained; Christopher's explicit instruction to
use the review rounds needed for this task authorizes the completion turn.

## Independent review

A fresh independent high-risk review found incomplete uncertain-operation recovery, production catch-up/quarantine and delivery-deadline rules. The revised design resolves those gaps. The same reviewer conditionally cleared explicit executor-quiescence wording and portable process probes; those exact corrections passed all 45 tests in a fresh temporary root. Private operational evidence remains private. This clears design implementation, not deployment acceptance.
