# Onboarding "could not check" label

## Ask

Chris asked for live checks of the installed Morpheus after merging #629, and for fixes to
anything they found. Running `morpheus init` twice in a disposable fixture with no remote changed
`hq/onboarding.md` on the second run. Branch protection and the Actions secrets went from
`could not check` to `detected`, although neither could be checked: the fixture has no GitHub
remote, so the network check cannot answer.

## Cause

- `collectStatus` keeps the recorded state when a detector returns `null`, which is correct.
- After the first run, that recorded state is the `[ ]` box that `parseOnboarding` reads as `todo`.
- `renderTask` chose the tag from `state === "unknown"` alone. On the second run it therefore
  printed `detected` for a check that never ran.
- The base CLI (70c297bc, run from its committed `dist/`) produces exactly the same file after two
  runs, so the bug predates #629.

## Change

- `TaskStatus.unchecked` is set when a detector ran but could not answer.
- The checklist tag, `formatStatus` and `summarise().unknown` read it.
- The merge step is `detectedStatus(task, saved, result)`, exported so it can be tested without a
  network.

## Result

- Three `init` runs on a fresh no-remote fixture now print `could not check` every time.
- Re-running `init` leaves `hq/onboarding.md` byte-identical.
- Tests:
  - Two new tests cover the second-run case and the answered case.
  - Removing `|| s.unchecked` from the renderer fails the new test: 1 failed, 34 passed.
  - `tests/onboarding.test.ts` and `tests/init.test.ts`: 110 passed.
  - Typecheck passes.

## Test plan

- `pnpm typecheck`
- `pnpm exec vitest run tests/onboarding.test.ts tests/init.test.ts` (110 passed)
- Mutant check: remove `|| s.unchecked` from `renderTask`; the new test fails.
- `pnpm compile`, then `node dist/cli/index.js init` three times in a fresh fixture with no remote.
  The label stays `could not check`, and the file is byte-identical.
- `morpheus complexity check`: no CCN findings.
- Full suite not run locally. `src/onboarding/` is not shared core, so CI runs it.
