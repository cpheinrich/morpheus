# Reusable refactoring prompt and per-function JSON

## Ask (2026-11-05, Chris's rollout mandate, via the Codex CTO controller)

The complexity toolkit (MO-26-11-05-21.48.00, #624) tells every project to run
`morpheus complexity check` and act on findings, but the tested behaviour-preserving refactoring
prompt (v1.5) lived only in Evo. Ship it with the installed CLI as part of the workflow, and give
`--json` the per-function rows the prompt's step 13 needs. No new skill, catalog, gate or
comparison framework; text and CI output unchanged.

## What was built

- `src/complexity/refactoring-prompt.md`: the canonical prompt. Rules 1–15 are Evo's v1.5 text
  byte for byte except one missing space (`default15` → `default 15`). Evo's private provenance
  (task id, pilot file names, version history with project-specific incidents) is replaced by a
  short generic note. A new "Supplying the inputs" table gives each task input its default:
  routine work declares the touched families and their focused tests; only a baseline declares
  the whole scope or a full suite.
- `pnpm compile` copies `src/complexity/*.md` beside the Python runner; `morpheus complexity
  prompt` prints the copy shipped beside the module (no options).
- `check --json`: the ran report gains `files`, every measured file with every Lizard row
  (`longName`, `start`, `end`, `ccn`, `cognitive`, `nloc`) plus `targeted`, computed with the same
  `isTouched` the findings use. Text, annotations, packet and exit codes are unchanged.
- AGENTS.md, the scaffold template, the complexity runbook (new "Refactoring a finding" section),
  cli-commands and architecture §7.12a say: refactor findings with the prompt, re-run the check
  after each changed family and inspect it by hand, report the summary and family metrics.

## Result

`node dist/cli/index.js complexity prompt` prints the source byte for byte. On this branch
`check --json` returns 12 files; for example `src/complexity/evaluate.ts` has 28 rows of which 4
are targeted. A real-Lizard test pins a CCN 15 helper (untouched, `targeted: false`, NLOC 17,
cognitive 14) beside a CCN 16 entry (touched, NLOC 18) in one file; a mutant that marks every row
targeted fails it. This branch's own check: passes, no findings.

**Budget fit.** Both instruction files kept within their byte guards by compressing wording, not
policy: AGENTS.md 19,986/20,000 (skills rows say "classified in"; the injected-copy reason moved
into a parenthesis), template 15,986/16,000 (external-mutation sentence restructured, "a ❗ inbox
item", "CI runs the same check", "why that scope").

**Design notes.** Before-metrics come from `check --all --json` in a detached worktree at the base
rather than a new compare or path option: Lizard is fast enough that measuring the scope is cheap,
and family membership stays the agent's judgement, as the prompt requires. No package search: no
generic module was written (file read plus a map over existing rows).

## Open questions

None blocking. The prompt's version moves only by a reviewed Morpheus change; Evo's copy can now
point at `morpheus complexity prompt` (Evo's own change, not made here).

and the template to their budgets and pinned phrases, init (scaffold text) and CLI tests (dispatch
