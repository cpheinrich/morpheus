# Enable the CCN complexity gate in Morpheus

## Ask

With both baseline refactors merged (Morpheus #629, Lakina #630), Chris asked on 2026-11-06 for
CCN above 15 to become a CI blocker in Morpheus and Lakina, keeping cognitive complexity advisory
and preserving the approved exceptions. That replaces the earlier instruction to keep a hard gate
off for these two repositories only; Evo is unchanged. For Morpheus: `enforce`, explicit `ccn: 15`
and `cognitiveWarn: 15`, keep the generated `dist/**` exclude, and add no exceptions, because none
is approved. The pin stays at b57041bf with no analyzer upgrade. A fresh full scan of the exact
tree was required, as were reversible probes of the gate and confirmation that the required
`pr / conventions` job runs the step. The Lakina half is LK-26-11-06-22.47.39 in that repository.

## What changed

`morpheus.json` only:

```json
"complexity": { "mode": "enforce", "ccn": 15, "cognitiveWarn": 15, "exclude": ["dist/**"] }
```

The gate is the existing "Check function complexity" step inside the required `pr / conventions`
job. No workflow, required check or branch-protection setting changes.

## Result

- **The tree is within the limit.** The full scan of the PR tree found no CCN error and no file
  that failed to analyse. Every in-scope file was measured: 609 files and 15,174 functions. The
  highest CCN is 15. Cognitive complexity warns in 101 functions; these stay advisory and were not
  refactored to clear them.
- **The gate does what it says.** In local probes that were never committed:
  - a new CCN 16 function fails (exit 1);
  - a function with CCN 7 and cognitive complexity 21 passes with a warning (exit 0);
  - an exception passes at its recorded CCN and fails (exit 1) once the function grows past it.
- **CI.** The step runs in the required `pr / conventions` job against the PR head's own
  `morpheus.json`. The caller skips that whole job on an unlabelled draft, so the step runs once
  the PR is labelled `agent-reviewed` or marked ready. The run on the labelled head is recorded
  below under "CI on the PR head".
