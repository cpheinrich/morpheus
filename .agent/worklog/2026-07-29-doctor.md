## Built

`morpheus doctor [--all]`. Deliberately the cheap half of `upgrade`: naming what is missing needs
no templating and no merge strategy, so it stays useful while conventions are still moving —
which is exactly when `upgrade` would be a liability.

## It found a bug in itself immediately

First run flagged Evo for missing `hq/finance/` and `hq/ops/`. The finance finding was **wrong**:
Evo declares `inherits: { finance: "darwin" }`, so that directory is correctly absent. Doctor now
respects `inherits`.

The `hq/ops/` finding stands and is genuine.

That is the useful property of a read-only check — a false positive costs a moment's inspection
rather than a bad mutation. The same logic in `upgrade` would have created a directory Evo
should not have.

## Also fixed

`pm claim` was running `git add -A`, sweeping whatever sat in the working tree into the claim
commit — the same class of bug that put a screenshot in a public repo. It now stages only the
roadmap item file.

Caught by using `claim` for the first time on this very item, which is the argument for
dogfooding a command rather than only testing it.
