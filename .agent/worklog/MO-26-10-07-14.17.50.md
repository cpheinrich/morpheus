# MO-26-10-07-14.17.50 — pins land where the person clicked

- Report: Chris, Lakina /hq/research, EXP-021 card's "Mixed" badge; the pin went to the left.
- Cause, confirmed in the page: `elementFromPoint` at the badge returns `a.hq-experiment-open`, a
  stretched link; `anchorFor` clamped the offset into the link's text box.
- Fix: `pickAt` walks `elementsFromPoint` for the first element whose own rect holds the point;
  otherwise the pin is drawn by page point (`byPage`, persisted with the pin).
- Verified on a second overlay (port 4399, scratch root) so Chris's live session was not touched:
  the pin anchored to `article:nth-of-type(4) > div:nth-of-type(2) > p > strong`, marker within 1px
  of the badge centre.
- Lesson recorded in chat with Chris: never navigate the person's overlay tab; test in another tab
  or another overlay.
