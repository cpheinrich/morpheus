# MO-26-09-30-21.17.19 — Let iOS workflows use a runner-provided build cache directory

PR [#308](https://github.com/cpheinrich/morpheus/pull/308). Companion to the Mac mini's
ephemeral CI VMs (agent-host-setup `ci-vm/`), which mount a persistent cache disk per
repository and slot and announce it to jobs as `MORPHEUS_IOS_CI_CACHE`.

## What shipped

- `ios-ci.yml` roots DerivedData and SwiftPM checkouts in the cache when the variable names
  an existing directory, reports `cached=true`, and skips the `actions/cache` SwiftPM step.
  Results, logs and screenshots stay per job under `$RUNNER_TEMP/ios-ci`.
- `ios-nightly-build.yml` and `upload-testflight.sh` root the release checkouts and archive
  DerivedData there under the same existence guard; the nightly SwiftPM cache action is
  skipped on cache runners too.
- Runners that do not set the variable, including GitHub-hosted ones, are unchanged.

## Evidence

- `pnpm test`: 56 files, 1525 tests green before the review fixes; `tests/workflows.test.ts`
  139/139 after them, with new cases for the cache path, the missing-directory fallback and
  both SwiftPM cache-step conditions.
- End-to-end on the VM lane is recorded in the Evo switch PR (EV-26-09-30-21.22.59).
