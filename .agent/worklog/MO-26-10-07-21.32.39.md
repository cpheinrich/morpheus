# Remove PR-conventions friction

Evidence: 1,298 failed `pr / conventions` logs across Morpheus, Evo, Lakina and Kairos. About 60% were
the missing `agent-reviewed` label. The old message "add agent-reviewed only after completing the
independent review" is the pre-#296 wording of the same check. It guards two things: the label is the
author's merge-ready attestation, and a record still in progress is not reported as a broken one.

**Label.** The first design passed an unlabelled draft as a warning. Review (RV-RACE) showed that
`gh pr ready && gh pr merge --auto`, and the GitHub Manager's undraft-then-auto-merge plan, could merge
in the seconds before the `ready_for_review` re-run registered. That design was replaced by a
caller-level `if:` on the `pr` job (`PR_CHECK_CALLER_IF`). A caller-skipped reusable job reports only
the caller job name; verified on Evo, where a caller-skipped job shows as `agent-review | skipped` with
no nested run. So `pr / conventions` stays unreported, which blocks merge without showing red. The gate
itself still fails any PR without the label. Alternatives rejected: commit statuses, which need
`statuses: write` in every caller plus branch-protection changes; and skipping inside the workflow,
because a skipped required check is satisfied.

**Record failures.** `morpheus review validate` calls `verifyReviewRecord`, extracted from
`checkLocalReview`, so local and CI cannot disagree. The previously documented local route
(`MORPHEUS_PR_BODY=... morpheus check pr`) failed on the missing label before it reached the record.

**`git show <sha>:morpheus.json`.** Reproduced from Evo and Lakina logs. The conventions checkout had
landed on `main`, and the head commit was absent. Git reports an absent commit as "path 'morpheus.json'
exists on disk, but not in '<sha>'", which hid the cause. The workflow now fetches `refs/pull/N/head`
and checks the head out. `committedConfig` names an absent commit. Ancestry failures, which Lakina also
showed as raw `git merge-base` failures, now name the pair.

**Evo no-op workflows.** Morpheus's reusable workflow and scaffold do not cause them. Evo's own
`ci.yml` ("Agent review", 1,808 skipped runs) and `agent-review-request.yml` (428 skipped runs) were
removed in darwin-health/evo#410, which is merged.

Validation:
- full `pnpm test` (1,840 tests) once, before review;
- focused local-review, workflows, init, cli-dispatch and agent-instructions tests after the rework and the merge;
- typecheck, lint, compile and pm validate.
