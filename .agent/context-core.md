# Morpheus session core

- Read the project instructions and the runbooks triggered by the task. Check the
  shared architecture contract before changing a feature used by other projects.
- Use the assigned task worktree, focused tests, independent review and protected
  delivery. Keep project-specific private data in the authorized project.
- Search for governing decisions, lessons and prior attempts once the task is
  known. Open the cited sections and check for superseding decisions.
- Read the relevant human inbox when handling replies or an inbox cycle.
