## Context

Darwin's Operations Desk set the layout and interaction model for HQ infrastructure desks, and
Lakina's Infra tab (LK-26-11-14-19.39.40) now follows it. `morpheus-kit/ops-desk` shares the
display primitives, but the layout, row, drilldown and verification contract existed only in
Darwin's source and worklogs.

## Approach

Write one public runbook with the reference behaviour, a short checklist, layout, terms and
interaction examples, the cross-owner health boundary, the browser checks and how a project opts
in. It uses synthetic examples only and is linked from `architecture.md`, `AGENTS.md`, the docs
index, the HQ design standard and `src/ops-desk/README.md`. No code changes.
