## Context

The Factory delegation plugin (`plugins/factory/`) is personal and opt-in, but the repository
did not say it was experimental, and nothing tested that normal Morpheus distribution leaves it
alone. Chris approved making the status explicit: the repository marks Factory experimental and
off by default, and a private per-machine setting enables it. Installing stays separate from
enabling, and a saved choice survives reinstalls and updates. Automatic dispatch is out of scope.

## Approach

- Repository-owned `release` status in `src/config.mjs` (`experimental`, default `off`) feeds the
  settings default and `bridge.mjs doctor`; the plugin manifests say "Experimental".
- The per-machine override is the existing `config.json` `mode`; no second switch.
  `bridge.mjs enable` refuses a missing or unknown mode instead of saving `off`.
- The installer's settings rule moves into `settingsMigration` in `install-lib.mjs`: it never
  replaces a saved factory config and writes nothing on a first install.
- Tests: fresh machine disabled and hooks inert, explicit on/off, preservation across reinstall,
  no default enrolment, and a Morpheus test keeping Factory out of init, bootstrap, session start
  and self install/update.
- README, skills, architecture §18.0 and decisions explain `factory@personal`, no automatic
  distribution, the coordinator as manager, and that automatic dispatch is not implemented.
