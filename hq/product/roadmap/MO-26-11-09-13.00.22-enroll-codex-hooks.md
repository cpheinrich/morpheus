## Context

The one-shot approval command addresses current pending hooks. An explicit project opt-in should also cover future eligible committed changes without repeating the command.

## Approach

Add a macOS login job and private per-checkout enrollment. Reuse the scoped Codex approval flow for each enrolled Morpheus checkout and stop scanning a project on disable. Preserve existing Codex approvals.
