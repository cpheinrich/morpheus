## Context

Try gstack across a real Morpheus workflow with a single session opt-in, without moving delivery ownership into a second system.

## Approach

Provide an opt-in lifecycle lookup with a managed, pinned gstack install for planning, review,
verification and release observation. Replay public historical web, CLI and iOS tasks and
record the selected handoffs, missing capabilities and evidence boundaries.

## Acceptance

- Default-off lookup and a reusable managed install for Codex and Claude after opt-in.
- The runtime and private profiles can be removed together without editing host settings.
- Routed handoffs specify inputs and evidence destinations, with no task or delivery writes.
- Historical web, CLI and iOS cases exercise routing and the ordinary Morpheus fallback.
