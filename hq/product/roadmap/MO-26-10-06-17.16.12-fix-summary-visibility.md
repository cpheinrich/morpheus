## Context

The GitHub Manager's first Morpheus run (ops run 37549663365, 2026-10-07) reviewed PR #327, fixed a
substantive finding and wrote its record, then had the merge refused: "repeat the manager review
summary as a visible paragraph outside the JSON block". The summary *was* repeated word for word.
It named paths in backticks, and the check compared it against `visibleProse`, which strips inline
code from the page but not from the summary, so any summary containing a code span can never
match. The ordinary `morpheus-review` record has the same check and the same latent bug.

## Approach

Add `visibleText` beside `visibleProse`: HTML comments and fenced blocks removed, inline code kept,
because inline code renders. Both record parsers use it for the summary check. `visibleProse` keeps
its job for waivers and record lines, where a backticked example must not count.
