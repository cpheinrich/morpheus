## Context

A cold Tantivy build adds roughly two seconds to the first task search. Start the build when the host opens the project MCP.

## Approach

Warm the content-addressed worktree index asynchronously at MCP launch. Reuse a valid cache or an in-flight build, and profile the launch, prompt and first result. Verify with a fresh Codex host before the first prompt. See [context search](../../../docs/runbooks/context-search.md).
