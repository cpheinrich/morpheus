## Context

Factory inspection can read the wrong archived Codex task or refuse a current desktop chat
before checking gateway quota. MCP processes may have a missing or stale process-level task ID.

## Approach

Use Codex's host-supplied per-request task identity before the legacy environment fallback,
preserving ownership checks and refusing malformed identities. Read in-place-compressed
rollouts without changing active-turn or permission validation. Keep unavailable metadata
distinct from gateway capacity and from the separately configured remote Paperclip pool.

## Acceptance

- Two chats sharing one MCP connection use their own host-supplied identities, even when the
  process names an archived chat. Model-provided task arguments cannot override that identity.
- Missing identity still refuses. Compressed metadata is validated under the same rules as
  plain metadata; completed turns and corrupt/missing files cannot start a worker.
- Focused plugin tests, root distribution regression, typecheck, compilation and CI pass;
  independent review clears before merge. Install the reviewed fix on this execution host
  and verify inspection through the updated bridge.
