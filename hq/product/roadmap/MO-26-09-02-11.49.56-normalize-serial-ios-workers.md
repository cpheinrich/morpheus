## Context

Evo's first scheduled nightly run after parallel-worker validation landed failed before tests with
`maximum-parallel-testing-workers requires parallel-testing`. The shared nightly workflow defaults
to parallel testing with six workers, but a serial caller that overrides only `parallel-testing`
inherits the independent worker-count default and forwards an invalid pair to `ios-ci.yml`.

## Approach

Normalize the dependent worker-count input at the nightly workflow boundary: preserve the caller's
requested ceiling when parallel testing is enabled and pass zero when it is disabled. Pin that
contract in the parsed-workflow tests so serial downstream callers remain valid without duplicating
Morpheus defaults.
