## Context

Chris wants one persistent Codex desktop interface, executing with Codex until a configurable allowance threshold, then supervising subscription-authenticated Claude on the same host and worktree. Manual overrides, model/effort and permission inheritance, read-only cross-agent memory, live output, crash cleanup and explicit per-machine opt-in are required.

## Approach

Build an independent package under `plugins/codex-claude/`. Prove installed protocol compatibility first; implement durable routing, owned process supervision, CLI/MCP tools and hooks, read-only live viewer, installation and diagnostics. Keep subscription billing exclusive, unknown permissions/usage explicit, and restrict initial execution support to verified macOS/POSIX capabilities. No install/init lifecycle enables it. Test lifecycle failures and complete independent review before merge.

## Acceptance

- Fresh Morpheus checkout and CLI installation do not activate delegation.
- Manual and automatic routing, persistent per-task overrides and operation exceptions.
- Same-host/worktree Claude execution, persisted session resume, model/effort and permission mapping with no silent widening.
- Structured questions and prose continuations return to Codex for supervision; user approvals remain distinct.
- Bounded output buffers, no duplicate run on reconnect, owned descendant cleanup after disconnect/crash, explicit background mode.
- Project-scoped memory exchange with separate ownership and memory controls respected.
- Live local demonstration, remote host validation, and explicit compatibility limitations.
