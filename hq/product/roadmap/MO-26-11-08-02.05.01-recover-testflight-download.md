## Context

A GitHub release download returned HTTP 504 on the macOS TestFlight runner before archive or upload. GitHub’s asset API served the same pinned binary.

## Approach

Fall back to the public asset API in both release installers after the normal download fails. Keep the existing per-architecture checksum as a mandatory check before executing the binary.
