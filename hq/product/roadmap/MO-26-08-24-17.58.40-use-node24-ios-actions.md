## Context

The first hosted Kairos consumer run passed, but GitHub annotated every official action still built
on Node 20 and explicitly deprecated `setup-java` v4. The runner currently forces those actions
onto Node 24, which is a temporary compatibility bridge rather than a clean CI contract. Leaving
the warnings in place hides new annotations and makes a future enforcement date an avoidable outage.

## Approach

Use the current official Node 24 majors published by each action owner: checkout v7, cache v6,
setup-java v6, and upload-artifact v7. Preserve checkout credential isolation and every existing
input, cache, and artifact behavior. Pin the majors in the workflow contract test, then rerun the
Firebase-backed Kairos caller to prove the current hosted runner supports the complete set without
compatibility warnings.
