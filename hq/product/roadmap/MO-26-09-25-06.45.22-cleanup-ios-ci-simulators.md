## Context

Evo observed abandoned simulators on persistent Macs. The reusable iOS test workflow has no simulator cleanup; PR CI and nightly release tests both inherit this gap.

## Approach

Create a unique disposable test destination using a Node action with an unconditional post hook. Reclaim only the owned device and its XCTest worker clones, including partial creation/failure/cancellation. Validate native behavior on the Mac mini and protect unrelated sessions.
