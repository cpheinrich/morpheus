## Context

An agent can currently claim a task, write a plan, or open a draft pull request
without proving that it has loaded the current project state or made a
substantive implementation checkpoint. That makes a stale session look active,
and lets a long-running session carry on after another agent changes the
canonical GitHub record.

Morpheus must make freshness and progress observable and enforceable at the
boundaries where local work becomes durable or externally consequential. That
is more than one item's worth of work, so this one is deliberately the policy:
the decision procedure, pure and independently testable, before anything is
wired to GitHub, a watcher, or an agent runner. Enforcement is
[MO-26-08-05-16.27.56](MO-26-08-05-16.27.56-gate-actions-on-lease.md).

## Approach

- A local, gitignored **context receipt** recording the remote SHA and a
  fingerprint per canonical record read. It never stores raw agent memory or
  conversation contents; local memory appears only as advisory source labels.
- A **session lease** with a five-minute term and three states — `fresh`,
  `refresh_required`, `unknown`. An unreachable remote is `unknown`, never
  assumed unchanged, and an expired lease is not a fresh one.
- One producer of fingerprints (`readInputs`) for both sides of the
  comparison, so drift is derived rather than asserted by the caller.
- A provider-neutral `SessionAdapter` and mock, so PM/session CI needs no
  Codex or Claude account.

## Acceptance

1. CI tests simulate fresh, stale, expired, unknown/offline, and
   never-loaded-anything receipts with a mock AI-session adapter; no test
   needs a provider account.
2. A receipt that does not cover the declared canonical records cannot certify
   as fresh, and the resulting lease names the records to load.
3. A lease older than its five-minute term degrades to `refresh_required`,
   including one restored from disk on resume.
4. Local session state is validated on read, so a corrupt file is
   distinguishable from no session at all and never reaches the guard as a
   type error.
