## Context

Morpheus #353 has a committed author review but lacks `agent-reviewed`, so the GitHub Manager
escalated a mechanical omission. Visual evidence currently passes URL checks without requiring
the author, independent reviewer, or Manager to inspect the rendered pixels. Manager sessions run
on Linux while iOS simulator builds already run on Evo's Mac mini.

## Approach

Validate the author's review against the current head before recovering a missing label. Have
authors capture final-build iOS screens, and require independent reviewers and Manager sessions to
open and inspect existing captures. Keep missing iOS evidence and actual judgment calls escalated;
the Linux Manager continues to capture web previews itself.
