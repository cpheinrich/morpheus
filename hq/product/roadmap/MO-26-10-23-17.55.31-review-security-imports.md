## Context

Chris approved a Security-only import compatibility option and, separately, the Manager's
review-only role for exact-head Security candidates. The normal Manager still skips Security
PRs. A distinct reviewer must clear a bounded candidate before Security can merge it.

## Approach

Add a Morpheus-only reusable review workflow called with the existing Manager credential. The
model session has a read-only target token and writes a decision artifact. A separate App job
verifies the Security candidate and current head, posts a review result bound to that head, and
triggers a dedicated conventions rerun. Ordinary Manager routing, CI events, branch protection,
other repositories and credentials remain unchanged. Document the effective permissions and
test forged identity, changed head, out-of-scope paths and missing review.

The Security engine and its own private caller are separate rollout dependencies. Final merge of
this item awaits #461's approved import repair so typecheck and all required CI can pass.
