## Context

Chris asked for an audit of the instruction stack (root and nested `AGENTS.md`/`CLAUDE.md`, the
scaffold template, the spec and the settings that affect loading) against the current Claude Code
and Codex guidance, with one proposal PR per repository for Morpheus, Evo and Lakina. The
[2026-10-07 trim](MO-26-10-07-21.31.01-trim-agent-instructions.md) set the shape: per-task
invariants in `AGENTS.md`, detail in runbooks read on demand.

What the primary sources say now (read 2026-11-12; links in the worklog):

- Codex stops reading project instructions at 32 KiB for the whole root-to-launch chain and cuts
  the file that crosses it. Morpheus (19,998 bytes) fit. Evo (46,512) and Lakina (33,468) did not,
  and nothing reported it: Morpheus's own file and the scaffold have size tests, consumers have none.
- Claude Code loads the whole file and advises under 200 lines. It reads `AGENTS.md` directly since
  v2.1.277, but only when no `CLAUDE.md` exists in the launch directory or above it.
- Both vendors now advise against "read these documents before every change" and against
  restating what the model can derive from the tree.

## Approach

- **Own `AGENTS.md`:** remove what is said twice or derivable from the tree, and split the
  review-loop paragraph into four labelled bullets with its sentences unchanged. No rule removed.
- **Scaffold callout:** say when to open upstream `architecture.md` (~290 KB) instead of "before
  reviewing or changing anything", as Evo and Lakina already do by hand; put the upstream-gap
  subsection back under its own heading; shorten it, keeping the facts its tests pin.
- **Spec §7.1:** state what each loader does, why the symlink stays, and what a nested file can
  and cannot carry. Drop the claim that an upgrade command rewrites a marked region.
- **`doctor`:** warn when a project's `AGENTS.md` exceeds Codex's 32,768 bytes, naming the line
  where the cut falls. A warning only.

Not done: removing the `CLAUDE.md` symlink, adding `.claude/rules/` or nested instruction files, or
changing any loader setting. Reasons are in the worklog.

## Acceptance

- Morpheus `AGENTS.md` is smaller, still names every gated command, resolves every runbook link
  and anchor, and keeps `### What makes a test count`.
- The scaffold no longer requires reading upstream documents before every change, and stays under
  its 16 KB budget.
- `morpheus doctor` warns on a 32,769-byte `AGENTS.md` and is silent at 32,768.
- Evo and Lakina each have their own proposal PR, usable whether or not this one merges.
