## Context

Every Morpheus-managed HQ should start with the same fast, private, client-side
search path instead of rebuilding the interaction in each project.

## Approach

Extend `morpheus web init` with the shared search dependency, a visible search
control in the HQ layout, a deployment-versioned private static index route,
and a starter allowlisted catalogue. Keep the generated styling neutral and
never discover repository files outside the catalogue that already determines
what the HQ publishes.

## Acceptance

- New Firebase-backed HQ scaffolds include a working search control and index.
- The index downloads only after search opens and is versioned per deployment.
- Re-running the scaffold remains non-destructive and idempotent.
- Existing route-gate and no-Firebase safeguards remain intact.
- Architecture documentation records the generated contract and privacy rule.
