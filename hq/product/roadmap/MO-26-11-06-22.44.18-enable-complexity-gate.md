## Context

The pinned Lizard check has reported Morpheus's function complexity as advisory since
MO-26-11-05-21.48.00. The baseline refactor (#629) brought every in-scope function to CCN 15 or
below, and Chris then authorized making CCN above 15 a CI blocker here and in Lakina, with
cognitive complexity left advisory.

## Approach

Set `complexity` in `morpheus.json` to `enforce` with explicit `ccn: 15` and `cognitiveWarn: 15`,
keeping the generated `dist/**` exclude and adding no exceptions. Prove the exact tree passes
`check --all`/`--ci`, then prove the gate with reversible local probes: a CCN 16 function fails,
a cognitive-only function warns, and an exception passes at its cap but fails on growth. The
existing complexity step in the required `pr / conventions` job enforces it; no new workflow.

## Acceptance

- `morpheus complexity check --all` and `--ci` exit 0 on the PR head, with no CCN error or
  analysis failure.
- The PR's `pr / conventions` run executes "Check function complexity" in `enforce` and passes.
