## Context

Installing factory on a Mac that had `codex-claude` exposed two installer gaps (#573): the
Codex plugin-creator helper had moved, and nothing migrated the old install. Wiring the
sub2api PoC gateway (morpheus-factory#20) then showed that gateway mode could not work from
a desktop session at all: `env:` key references and `FACTORY_ADMIN_*` are read from the
bridge service's environment, which is whatever session first started it, so quota read as
unknown and routing stayed native. Claude quota also read only the 5-hour window, so a
spent week looked free.

## Approach

- `exec:command` secret references (no shell, value never logged) for gateway keys, and a
  config `admin: {emailRef, passwordRef}` for the quota login, with env fallback.
- Gateway usage is the most-used live window (5h and 7d for both providers).
- `doctor` shows each gateway's quota, whether its key resolves, and the admin source.
- Installer: search known helper locations, and migrate a `codex-claude` install step by
  step (settings minus the reversed `threshold`, status line, Claude/Codex registrations,
  marketplace entry, install copy).
