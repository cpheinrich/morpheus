## Context

A Fleet worker can hit its invocation deadline after preparing useful work. The
controller currently receives a generic failure and must recover files by hand.

## Approach

Allow the worker to name completed artifacts in an explicit per-invocation
checkpoint. Replay the existing private artifact path only after the guardian
verifies cleanup and preserve a distinct deadline failure.

## Acceptance

- A verified deadline returns an explicit failure and only valid declared partial files.
- A failure without a valid manifest still reports the deadline.
- Normal completion, cancellation, file boundaries and limits keep their existing behavior.
