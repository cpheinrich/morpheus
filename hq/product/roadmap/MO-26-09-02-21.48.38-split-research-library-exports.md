## Context

Lakina's first downstream build against Morpheus #204 panicked because the single research-library
entry exported both browser verification and `node:fs` catalog loading. Turbopack followed that
boundary into a client chunk even though the component imported only the browser function.

## Approach

Split the package into shared, server, and client entry points; keep the root entry browser-safe;
add a regression test over the client source; and rerun Lakina's real Next.js build before merging
its adoption.

## Acceptance checks

- The client entry has no Node built-in import or server-module edge.
- Existing publisher and catalog tests remain green.
- Lakina's Next.js production build no longer panics.
