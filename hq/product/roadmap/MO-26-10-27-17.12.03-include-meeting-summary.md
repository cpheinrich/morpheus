## Context

Lakina's first current Gemini-note intake needs the authorized Zoe group notification to carry the
note's actual summary, while Evo's established notification should retain its concise generic
format. The notice gate must fail closed if a summary-enabled profile's journal omits that text.

## Approach

Add an opt-in \`includeSummary\` notification-profile field, validate the journal summary with the
same one-line and length bounds as canonical note summaries, and include it only for profiles that
request it. Preserve the existing output for other profiles and document the journal requirement.

## Acceptance

- Summary-enabled authorized profiles include the bounded journal summary in the formatted text.
- Missing, multiline, or oversized summaries refuse before delivery.
- Profiles without the option retain a summary-free notification.
- Focused tests, typecheck, compile, PM index, independent review, and CI pass.
