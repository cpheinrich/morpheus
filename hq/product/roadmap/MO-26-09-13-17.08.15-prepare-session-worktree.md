## Context

Sessions could read stale code while context refresh certified local records against a newer remote SHA. A conversation is not an implementation task; creating a worktree for every question wastes checkouts. Supersedes abandoned PR #243 and its unmerged roadmap item MO-26-09-13-15.14.54.

## Approach

Fetch canonical trunk at startup, fast-forward only clean local trunk, and refuse stale source certification. Create isolated worktrees when new tasks are claimed; explicitly resume existing task worktrees and retain optional session associations. Ship behavior through the shared CLI and existing standard hooks. Validate with real Git remotes, stale/dirty/diverged states, claim/resume, and independent review.
