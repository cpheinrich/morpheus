## Context

The service can enroll multiple Git projects, but the Studio supervisor currently binds its one slot to one repository. A second project cannot run without replacing the first.

## Approach

Allow an optional map of additional Git projects to separate accounts and absolute mirrors. Route by the exact admitted project while preserving one slot, one journal. Each extra route has a narrowly configured supervisor-to-executor command.

## Acceptance

- Existing single-project and fixture configuration works unchanged.
- Two Git project IDs choose their own mirror and exact executor project.
- Unconfigured or malformed routes cannot launch; admission recovery still uses the correct project’s worker result store.
- Focused routing, source isolation and restart tests pass.
