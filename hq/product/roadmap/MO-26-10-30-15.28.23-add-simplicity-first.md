## Context

Chris audited the CD pipeline, which had been failing for a long time. He found that much of the
friction came from too much complexity and too many gates. He had asked for some of those gates
himself, and agents then read the requests too strictly. A same-day example is the 2026-10-30
review decision: asking for approval before the original reviewer could finish an incomplete review
was never intended.

Chris wants this to be a durable preference in Morpheus and every Morpheus project. Any design or
plan, from a small feature to a large system, should start from the simplest version that meets the
requirements. Before implementation it should get a quick pass that asks what can be removed while
still producing the same result in the common case. Complexity, gates and authorization
requirements are added only when the system's observed behaviour proves they are needed.

## Approach

Use the existing paths and add no new mechanism:

- `architecture.md` §2 gains the principle, because it is the specification.
- Morpheus's `AGENTS.md` and the scaffold's `agents()` template state it as a working convention,
  so every new project starts with it.
- One `INSTRUCTION_ANCHORS` entry makes `morpheus doctor` name the rule in any existing project
  whose `AGENTS.md` lacks it. That is the existing route for template guidance to reach projects
  scaffolded earlier, and its test holds the template and Morpheus's own file to it.
- A `decisions.md` entry records why the rule exists and what it deliberately is not.

The rule is deliberately not a CI check or a required review artifact. A check that demands proof of
a simplification pass would get ceremony, as the folder-README decision found. It also does not
remove any existing gate. Removing a gate stays an explicit decision.

## Acceptance

- `AGENTS.md`, the scaffold template and `architecture.md` state the rule in consistent words.
- `morpheus doctor` warns about an `AGENTS.md` without the rule. Both the template and Morpheus's
  own `AGENTS.md` pass that check.
- Morpheus's `AGENTS.md` stays within its 20,000-byte budget, and no rule is lost to make room.
