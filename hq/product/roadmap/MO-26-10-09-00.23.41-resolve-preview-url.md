## Context

The first live run after MO-26-10-08-22.58.06 (ops run 37893093756) could not capture Evo #378's
screenshots: the brief told the session to read the preview URL from GitHub deployment records,
and the `morpheus-gh-manager` App has no Deployments permission, so both REST and GraphQL returned
403. Adding the permission needs a passkey re-authentication and installation re-approval.

## Approach

A deterministic `morpheus gh-manager preview-url <repo> <pr> <sha>` the session runs. It tries
deployment records first; without access, it binds Vercel's own `vercel[bot]` pull request comment
to the commit: the comment's embedded `inspectorUrl` must equal the `target_url` of the head
commit's successful `Vercel` status, and only then is its `previewUrl` used. The comment's author
is a GitHub App identity no person can post as. The brief points at the command instead of
describing API calls.

## Done when

The command is tested against both sources and refusals, the brief uses it, and a live run
captures #378's screenshots.
