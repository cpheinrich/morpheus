## Context

Editing one indexed record in Morpheus added 1.26–1.28 seconds of rebuild time to the next
search across 1,012 indexed files. Long sessions can hit that pause repeatedly.

## Approach

When the MCP detects a change, keep using the last ready index for the current worktree and
kind filter while the replacement builds. Mark partial results and cite only unchanged files.
Exact reads use the live file. Search switches automatically when the replacement is published.

Verify in one MCP session across multiple file changes and follow-up searches.
