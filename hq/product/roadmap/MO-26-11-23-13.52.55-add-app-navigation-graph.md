## Context

Teams want to browse an app as a set of connected screens in research and internal analytics, with the same screenshots, wireframes and controls available from each screen.

## Approach

Add the graph to the shared research viewer. Reuse the existing study schema and screen selection. Provide a reusable capture-refresh skill for safe synthetic navigation and exact release provenance.

## Acceptance

- The viewer renders clickable graph nodes from study screens and verifiable edges from transitions.
- Graph and screen list select the same detail and preserve deep links and browser history.
- The graph is read-only, has pan, zoom and fit controls, and works for existing version 1 studies.
- Projects can reuse the skill for frontend capture checks and verified App Store study refreshes.
