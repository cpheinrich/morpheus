## Context

Lakina and Evo have large Markdown histories. Measure whether QMD improves evidence
retrieval over ordinary agent file navigation before adopting it. The user requests
30 representative questions per project and an open Morpheus PR with the findings.

## Approach

Freeze tracked documentation and independently specified evidence sections before
running comparisons. Measure QMD lexical, vector and hybrid retrieval, then paired
fresh-agent runs with ordinary search versus ordinary search plus QMD. Report
recall, latency, token usage, failures and limitations. Keep private questions,
source excerpts and transcripts out of this public repository.

Deliver a reproducible harness, redacted measurements, analysis and recommendations.
No production integration, infrastructure migration or merge is authorized here.

## Findings

Completed 300 search calls and 120 paired fresh-agent sessions. Ordinary navigation
located all required evidence; QMD did not demonstrate a recall or completion-time
benefit in this curated sample. Two valid alternative QMD answers are reported
separately from frozen-label scores. The long-tail worklog workload needs a more
targeted trial before adoption.

Report: `qa/audits/2026-09-24-document-retrieval.md`.

Chris requested a settings-optimization follow-up, not a defense of the original
configuration. Tune native QMD query recipes, candidate counts, reranking,
transport and source-return workflow, then validate a promising configuration on
new worklog-detail questions. Compare substantial question-to-evidence savings at
similar recall, not just sub-millisecond search-engine speedups.

Follow-up: `qa/audits/2026-09-25-qmd-performance-tuning.md`.

Completed 990 backend observations, 16 development agent trials and 80 repeated
validation sessions. Keyword CLI/full-source retrieval was faster, but typical
paired completion improved only 1.17x (2.84 seconds), with 100% source-audited
recall in both arms. It did not meet the large-speedup target. Preserved a separate
36-row interrupted setup attempt instead of pooling its database failures.
