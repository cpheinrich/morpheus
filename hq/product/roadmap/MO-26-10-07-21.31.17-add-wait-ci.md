## Context

`morpheus profile` measured polling of running processes and CI as about 24% of agent busy time and
20% of tokens across Claude and Codex transcripts. Each poll re-reads 140–380k tokens of context to
learn "still running": one session ran `gh run view <id>` 31–46 times, another `gh pr checks
--watch` 21 times, others `sleep` loops around `gh run view` or `until grep …; do sleep 5`.

## Approach

`morpheus wait-ci [<pr|branch>] [--repo owner/name] [--timeout 45m] [--required-only]` blocks in
one tool call until every check on the PR head finishes or the timeout passes, polling `gh` with
internal backoff and printing nothing while it waits. It then prints a compact digest: the verdict,
one line per failed or cancelled check with its URL, and for each failed Actions job the trimmed,
de-duplicated, ANSI-stripped tail of `gh run view --log-failed`. Exit 0 green, 1 failed, 2 timeout,
3 usage or `gh` error. A head SHA that moves mid-wait is reported, never mixed. A `conventions`
failure caused only by the missing `agent-reviewed` label is labelled as the known label race.

Pure logic (check parsing, verdict and exit mapping, log trimming, SHA change, digest) lives in
`src/wait-ci/` behind an injectable `gh` runner, with fixture tests. AGENTS.md, the scaffold
template and architecture.md replace "do not poll" prose with the command.
