## Context

Codex's right-panel "comment" tool lets an operator tap a preview (often a serve-sim
iOS stream), leave one or more text comments, hit send, and have the agent receive
the batch with frame context. Grok and other agents have no equivalent panel, so
visual QA today falls back to ad-hoc screenshots in chat.

Evo's ios-qa skill already launches serve-sim; the missing piece is a Morpheus-native
comment loop that any company project (Evo, Lakinacapital, Kairos, …) can reuse —
not an Evo-only hack.

## Approach

1. **Local web app** — thin overlay that sits on a preview URL (serve-sim or any
   local stream). Operator taps → adds text comments (multi) → Send.
2. **Structured batches on disk** — each Send writes a gitignored batch under a
   project-local path (e.g. `local/qa-comments/`) with: project id, frame/screenshot
   ref, `comments[{x,y|region, text}]`, timestamps. Agents poll or are pointed at
   pending batches.
3. **CLI** — `morpheus qa comments pending|resolve` (and later `watch`) so any agent
   runtime can list and close batches without inventing paths.
4. **Cross-project** — live in Morpheus; company projects consume via the CLI and
   an optional hook from ios-qa / `preview.sh`. No secrets; no force-push.

First slice: design + schema stub + CLI surface + on-disk layout. Full overlay UI
and serve-sim wiring follow in the same claim or a follow-up item.
