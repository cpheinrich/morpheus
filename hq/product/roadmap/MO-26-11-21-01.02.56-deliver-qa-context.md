## Context

QA implementation currently receives a bounded text brief while screenshots and diagnostic packets remain in the reporting project. Chris authorized complete private task context for iOS and web QA, implementation and independent review, protected merge, and downstream integration. The existing live-web capture work (MO-26-11-21-00.05.31) stays with its owner; this task owns transport into Factory.

## Approach

Extend existing Fleet private transport to accept immutable digest-bound controller-supplied input files, scope retrieval to the exact admitted task, and materialize them privately for workers without source-project credentials. Preserve retries, source binding, cleanup, output artifacts and no-data-on-dashboard boundaries. Support screenshots and diagnostic JSON for Codex and Claude; existing tasks remain compatible. Use synthetic end-to-end tests including unauthorized cross-task reads, digest changes, limits and path attacks. No original user evidence in this public repository.

## Acceptance criteria

- An authenticated controller can attach bounded private JSON and images, atomically bind their manifest to admission, and retry the exact request idempotently.
- Only the exact admitted worker can retrieve task inputs; integrity and safe file paths are verified before execution.
- Both providers see private local input paths and can inspect images; context never enters public status, Git or output artifacts automatically.
- Tests prove controller to worker materialization and isolation; documentation explains deployment compatibility and downstream API.
- Independent Fleet review and required CI pass before protected merge.
