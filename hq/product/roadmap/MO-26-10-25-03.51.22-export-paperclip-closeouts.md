## Context

Paperclip is the live conversation surface while Git retains reviewed, versioned
closeouts. Existing PM and Markdown inboxes remain until a qualified migration.

## Approach

Build an optional first-consumer operator exporter in `scripts/paperclip-closeout/`.
Require a bounded explicit frozen input and exact company/issue/thread target,
record deterministic content and attachment-byte identities, preserve previous
snapshots, and refuse observed churn or unsafe filesystem paths. Keep API acquisition,
task completion, PM updates, credentials and provider launches out of this prototype.

See [operator contract](../../../docs/paperclip-closeout.md). Review and release are
coordinated by the parent CTO task after implementation validation.
