## Context

Chris wants the Morpheus Context MCP used by every agent on every Morpheus project, including
Claude sessions, subagents, reviewers, Factory workers and collaborators' machines, without
anyone approving or installing it by hand. A baseline on Zoe's mini (Evo, after evo#861) showed
Codex using the MCP for every record lookup, while Claude ran one MCP search and then fell back
to `cat` and `grep`. Claude prompts before starting a project `.mcp.json` server, and
codebase-memory's own Grep hook answered record searches with section headings.

## Approach

- `context install` pre-approves `morpheus_context` in `.claude/settings.json`
  (`enabledMcpjsonServers`), verified in an interactive trusted folder.
- A Claude `PreToolUse` hook on Grep and Bash adds cited Tantivy excerpts, tagged
  `[morpheus-context]` with a visible notice, when a search targets project records. Codex is
  unchanged; it already uses the MCP and new Codex hooks need per-user trust.
- `.cbmignore` excludes the record globs from codebase-memory, so the two hooks do not overlap.
- Auto-update stops registering a user-level Claude entry and removes the one it wrote earlier;
  Codex and Cursor user registrations stay.
- Roll the setup to every managed project, then re-run the Evo probe on the mini.
