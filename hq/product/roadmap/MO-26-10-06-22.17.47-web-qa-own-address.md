## Context

Lakina's Google sign-in failed inside the web QA overlay. Its Firebase browser API key allows
`http://localhost:5173/*` as a referrer; the overlay served the site from `localhost:4342`, so
Firebase answered `auth/requests-from-referer-http://localhost:4342/-are-blocked`. The browser
calls Google directly, so the proxy cannot rewrite it. Widening a project's key allowlist for a QA
tool is a security change each project would have to make; the overlay should fit the project.

## Approach

A `{port}` placeholder in `qa.web.command` lets the preview choose the dev server's port. When it
starts the dev server, it moves it to the first free port above the site's and listens on the site's
own address. Attach mode, and commands without `{port}`, keep the separate port and `start` warns.

Acceptance: Lakina's `/hq/sign-in` through the overlay at `http://localhost:5173` reaches the Google
popup with no referer error (verified 2026-10-06; the dev server ran on 5174).
