## Context

Apps using the same screen-comment editor need one upstream Swift source and a
repeatable release path. Local package copies can diverge when a shared fix is
shipped from an app checkout.

## Approach

Expose independently selectable products in the root SwiftPM manifest and import
Screen QA with recent launcher, batch notes, handoff, and editor improvements.
Reuse the iOS simulator workflow with the self-hosted Mac pool. Distribute the
upstream change workflow through the managed project skill registry.

After this release merges and receives its initial tag, stage the first consumer
adoption in a separate draft. See [acceptance](../../../qa/acceptance/publish-swift-packages.md).
