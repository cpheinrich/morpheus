## Context

Issue #281 documents reviewer elapsed-time estimates several times greater than actual runner
duration, causing false budget failures. The prompt currently asks the reviewer for a number
it may be unable to observe, even though the author can capture runner metadata.

## Approach

Assign measurement to the author using runner duration or actual per-invocation clock readings.
Emit version 2 review records with a timing source, milliseconds and evidence for every turn;
validate elapsed-minute conversion without rounding. Preserve version 1 compatibility and all
existing budget, outcome, floor, coverage and same-reviewer rules. No provider transcript upload.

## Acceptance

- New packets never request a workload estimate; they emit the measured-time record shape.
- Version 2 requires timing for every turn and rejects inconsistent elapsed minutes.
- Regression reproduces #281's measured duration versus the erroneous estimate.
- Real duration boundaries still enforce existing floors and ceilings; old records remain valid.
