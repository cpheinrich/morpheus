## Context

In the evo#863 test the author found the decisive prior record through the Context MCP, but the
independent reviewer read only code and SDK source and no project records. Chris: reviewers must
orient with the context MCP before reviewing, and authoring agents in every Morpheus project should
suggest the context files a reviewer should read.

## Approach

- The reviewer contract makes orientation an explicit first step (overview, task search, cited
  reads of every Suggested context path) and asks for a Context read list in the response.
- `review prepare` adds a Suggested context section: the ticket and acceptance files, then a line
  the author replaces with the governing records. The CLI carries it to every project.
- The review record gains optional `contextRead`; a missing list warns (`review-context`), never
  refuses, and CD repair verification ignores warnings.
- AGENTS.md, the scaffold template and the independent-review runbook name the author step.
- Added by Chris during review: the reviewer reads the PR description and its Test plan, reruns
  what settles a doubt and adds checks where the plan falls short; the packet says how to fetch it.
