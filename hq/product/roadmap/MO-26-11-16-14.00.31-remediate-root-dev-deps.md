## Context

The 2026-11-16 weekly technical-health audit found one high and three moderate advisories in the
root development graph. Existing pull request #704 owns the minimatch advisory. The remaining
unowned findings are `@vitest/mocker` under Vitest 4.1.11 and `re2js@2.8.6` under the current
Firebase dev dependencies. Neither is installed in the production graph.

## Approach

Update Vitest within its declared v4 range to the first fully patched 4.1.12 release and update the
lockfile-only `re2js` resolution to a patched version within Firebase's declared compatible range.
Keep #704 as the separate minimatch vehicle. Run the focused test, type, lint, compile, PM, frozen
install, and full dependency-audit evidence, then leave a governed draft pull request for review.

## Acceptance

- Root `pnpm audit --json` reports only the minimatch advisory already owned by #704; root
