## Context

The session-start hook that runs `morpheus context brief` existed in two of eight registered
projects. Seven of eight never declared `context.handle`, so their sessions certified `fresh`
without `hq/team/<handle>.md` in the required set — the one record a human replies in.

Both are the same root cause: **`morpheus init` skips any file already present**, so a scaffold
only ever reaches new projects. `doctor` had been reporting both all along; nothing could act on
the report.

## Approach

`morpheus context install` — idempotent, merging rather than overwriting, refusing any file it
cannot parse. Three targets: `.claude/settings.json`, `.codex/hooks.json` (Codex reads the same
schema in its own file), and `context.handle`. `init` uses the same path so re-running it on an
established repo works, and `doctor` names the command.

Codex will not run an untrusted hook and says nothing when it declines, so the command prints the
one-time `/hooks` trust step whenever it writes that file.
