## Context

Pull requests pile up. On 2026-10-01 there were 20 open across Evo, Lakina and Morpheus, and 13
of them failed `pr / conventions`; in the sampled logs the cause was an independent review that
never finished, or missing visual evidence. The authoring session had ended, and nothing else
listens for a stalled review loop. Chris wants a watchdog that runs on a cadence independent of
any machine, acts without waiting on a human or on the original author, and leaves an audit
trail of what it did and why.

## Approach

A `morpheus-gh-manager` GitHub App and a private operations repository, following the
`morpheus-security` pattern: the operations repository alone holds the App key and the Claude
subscription token and owns the schedule; a target repository opts in with a reviewed
`.github/morpheus-gh-manager.json` on its default branch.

Each run is three stages. A deterministic sweep (`morpheus gh-manager sweep`) lists open pull
requests and buckets them from facts, with no model. One fresh Claude session per pull request
that needs judgment then reads the reviews already recorded, merges when the record is clear, and
otherwise conducts one more review, fixes its own findings in the same session and records both.
A deterministic apply step revalidates the head and the policy before enabling auto-merge,
closing, or labelling.

The review contract gains a manager turn: the manager is a fresh session, so it may review; it
may also fix what it finds, because the author is not listening. Human-gated paths, non-collaborator
authors, bot lanes and recently active branches are escalated or left alone.

Rollout: Evo first, acting immediately and watched for about twelve hours, then Lakina and Morpheus.

Cooldowns are 8 hours for a ready pull request and 48 for a draft; an abandoned draft that has not
done its roadmap item's work is marked incomplete rather than finished for its author. Issue
triage is the follow-up MO-26-10-01-12.55.11.
