## Context

The pinned Lizard (`7f14ea5`, tag `morpheus-analyzer-2026-11-06`) loses every function that follows
a template literal type with an interpolation inside a TypeScript interface or `type X = { … }`
body: the body skipper closes at the interpolation's `}`, the orphan backtick opens a template
literal state that never closes, and the rest of the file folds into `*global*`. Fixed in the fork
(upstream terryyin/lizard#562), integrated as `484bbd0` under the immutable tag
`morpheus-analyzer-2026-11-06-ts`, first parent `7f14ea5`.

## Approach

Move `LIZARD_PIN` to `484bbd0` and its tag (wheels unchanged), add a `canary.ts` that compiles
under `tsc --strict` and must measure `choose` CCN 4 / cognitive 1, `run` 3 / 2 and `*global*`
1 / 0, and a test that installs the previous pin and asserts the canary refuses it. Existing
JavaScript, Swift and TSX canaries stay. No policy, mode or Evo enforcement change.

**Acceptance.** New pin installs and passes `complexity install --check`; old pin is refused by the
canary; existing contracts pass; `complexity check --all` on frozen Evo `ab95f3d` compared against
`7f14ea5` with every delta reported; independent review and CI before merge.
