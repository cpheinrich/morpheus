## Context

The reusable iOS workflow currently accepts one runner string. A later,
separately reviewed hosted-fallback drill needs an exact validation-only label
conjunction without changing ordinary local or hosted routing.

## Approach

Add an optional JSON-array string, validate it on hosted Ubuntu before native
assignment, and consume canonical output with Actions `fromJSON`. Keep the
ordinary string route, complete native tests and evidence unchanged. This task
owns source and offline/CI validation only; consumer pins, runner inventories,
arming, dispatch, cancellation and actual delivery are separate work. The PR
remains draft with auto-merge off until root coordinates independent review and
releases the source merge gate.
