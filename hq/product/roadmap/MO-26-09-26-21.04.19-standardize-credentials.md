## Context

Lakina proved local companion discovery; Evo and Darwin need a portable shared convention without duplicated helpers.

## Approach

Lift discovery, setup, sync and process forwarding into Morpheus; scaffold metadata and explicit setup instructions, then adopt in consumer repositories.

## Acceptance

- A tracked portable pointer supports private project-local and shared remote companions.
- Setup creates or clones explicitly, preserves existing work, validates origin and visibility,
  and never replaces a global wrapper. Agents are told to set up missing clones.
- Worktrees, relative paths, override precedence, safe sync and rename migration are tested.
- New project scaffolding documents the contract; collaborators have a repeatable migration prompt.
- Lakina, Evo and Darwin adopt the shared CLI after this implementation merges.
