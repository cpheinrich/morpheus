## Context

Evo and Kairos independently need Vercel previews for agent-authored commits without adding the
agent identity to a paid Vercel team. Evo carries a working Vercel CLI workflow while Kairos carries
an owner-authored mirror-branch workaround. Copying either project-local implementation leaves the
deployment contract to drift.

## Approach

Add an atomic reusable Vercel CLI workflow with explicit caller secrets, same-repository pull
request protection, preview URL reporting, and production handling. Keep agent review entirely
separate. Convert both projects to thin callers after the reusable workflow reaches `main`.
