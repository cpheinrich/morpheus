## Context

The first auto-update rollout assumed a stale installation already supported `morpheus self
update`. A collaborator's pre-#167 CLI rejected the whole `self` group, so the fallback could not
bootstrap itself. Existing project hooks also called that stale CLI directly.

## Approach

Add a checked-in session shim that detects pre-`self` installations without mutating them. After
explicit consent, a version-independent script clones reviewed Morpheus `main` and invokes that
clone's committed CLI to install the standalone package, register the project and enable hooks.
Generate the files for new projects, safely repair existing provider hooks, prove the pre-#167
path in tests, then roll the generated files through every registered project.
