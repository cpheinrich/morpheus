## Context

[Issue #759](https://github.com/cpheinrich/morpheus/issues/759) reports an unattended native Claude can_use_tool request that is forwarded without an answer and hangs until deadline. The classifier safeguard must remain effective.

## Approach

Use the existing Fleet Claude relay to provide actionable denial for native tool requests, or use an already-supported durable question owner if tracing establishes one. Never autoapprove or widen worker authority. Preserve cancellation, gateway quota/overage refusal, session binding and recovery. Factory Fleet Standard implementation and a fresh independent Fleet review own all code changes.
