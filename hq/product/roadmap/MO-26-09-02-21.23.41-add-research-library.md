## Context

Lakina proved a private, immutable book library, and cpheinrich.com, Kairos, and Evo now need the
same capability. Leaving the publisher, integrity contract, and browser verification in Lakina
would copy security-critical code into every project. Babel is already the source-neutral
acquisition and Docling conversion package and remains independent.

## Approach

Lift deterministic bundling, create-only publication, remote verification, catalog parsing, and
browser byte verification into Morpheus. Add a non-overwriting initializer and a documented
project-owned seam for Firebase rules, routes, branding, principals, and catalog data.

## Acceptance checks

- Initialization preserves every existing file under `local/research-library/`.
- The publisher consumes Babel's canonical directory without importing or coupling to Babel.
- Bundle and reader object names are content-addressed; the catalog advances only after both verify.
- The reusable parser rejects the wrong bucket, floating object names, invalid shape ids, and
  readers derived from a different source bundle.
- A fresh project can initialize, publish, verify, and render a private book using the public
  `morpheus-kit` dependency.
