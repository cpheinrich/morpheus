## Context

A fresh Codex desktop session could not reach GitHub with networking disabled.
With networking enabled and workspace protections still active, the refresh
read the remote tip but failed when Git tried to write a temporary ref.

## Approach

Verify the existing checkout against two live trunk observations and an
ancestor check. Keep checkout preparation and read evidence as separate steps.

## Acceptance

- A checkout containing the advertised trunk gets an online context receipt
  in workspace-write mode with networking available and Git metadata protected.
- A moved, unreachable, or missing tip cannot certify an older source state.
- The existing startup and claim workflows keep their source preparation.
