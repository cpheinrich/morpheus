## Context

Evo controller-only pull requests queued the two Mac test jobs just to run Git path detection. That competing demand delayed real app runs when the native pool was full or the dispatcher could not discover demand.

## Approach

For ordinary scoped PRs, prove the exact checked-out PR merge and existing Git pathspec comparison on hosted Linux. Skip the Mac job only when this succeeds and proves no native inputs changed. An absent or inconclusive preflight leaves the existing native scope and tests in control. Preserve the existing explicit CD source and runner-selection routes.

## Acceptance

- Existing Git fixture behavior, native test check identity and explicit delivery routes are preserved.
- A successful unchanged proof avoids a native runner reservation. All other results use the existing route.
- Workflow lint and all directly affected test suites pass.
