## Context

The standalone brand retrofit embedded a worktree directory name and derived token prefix even when
`morpheus.json` carried the project identity, and its generated READMEs promised raw media was
ignored without writing those ignore rules. Separately, the shared imagery parser stripped Evo's
optional `editorialBoundary` governance field. Issues #122 and #123 are the same retrofit defect;
#149 is the adjacent shared schema correction small enough to verify in the same brand contract.

## Approach

Resolve brand identity from explicit flags, then the project manifest, then the directory fallback.
Make `brand init` append only missing exploration-media ignore rules. Declare and test the optional
editorial boundary without changing manifests that omit it. Also make the smaller local `check pr`
failure in #123 name the `MORPHEUS_PR_BODY` input it actually reads.

## Acceptance

- A branch-named worktree produces brand files named for the manifest and the canonical token prefix.
- Existing `.gitignore` policy is preserved; required raw-media boundaries are added once.
- `readImagery()` preserves `editorialBoundary` and still accepts older manifests without it.
- A local missing-body convention failure names `MORPHEUS_PR_BODY`.
