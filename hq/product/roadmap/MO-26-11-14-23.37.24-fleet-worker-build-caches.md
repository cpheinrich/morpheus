## Context

Xcode jobs on dedicated Fleet execution accounts must write private tool caches and reach CoreSimulator. The workspace sandbox blocks CoreSimulator even after cache directories are writable.

## Approach

Reuse the existing Full Access mode for explicitly enrolled Git workers under a private non-root account and a root-protected configuration. Keep worker caches in that account and build products per checkout. Keep capacity and CI admission as configured.

## Acceptance

- A worker-owned config cannot select Full Access for a Fleet attempt.
- A qualified Xcode worker can write its own cache and use an owned disposable simulator.
- An unchanged enrollment continues to use workspace-write. Roll out only on verified hosts and record the exact qualification.
