## Context

Desktop session hooks omit Homebrew from PATH, so a current installed CLI and saved opt-in are mistaken for an absent installation. Hook-status failures also trigger the same consent prompt.

## Approach

Recover common tool directories, preserve saved yes/no and invalid preferences, distinguish hook-health errors from missing CLI capability, and make the installed Node runtime available to managed Git hooks. Verify actual shell execution with restricted PATH and regenerate the checked-in scripts.
