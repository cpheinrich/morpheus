## Context

An audit of the GitHub Manager's escalations (2026-10-08) found Evo #378 escalated only because a
`/dataset-collection/` screenshot was missing. That page is public web, and the PR's Vercel
preview serves it without sign-in, so the manager could have captured it. Chris asked for the
manager to do that and to keep iterating until it works on Evo and Lakina.

## Approach

The session screenshots the PR's own web preview with a pinned Playwright, checks each image, and
lists the files in its decision with placeholders in the body. The deterministic apply step
validates the images, publishes them to an orphan `gh-manager-evidence` branch in the same
repository (content-addressed, no new credential), and substitutes the links. A repository opts in
by approving that branch's URL prefix in `review.visualEvidence`. iOS screens stay an escalation.
