## Context

A Codex delegation labeled as a gateway run used the coordinator account. Worker model and speed must be independent of interactive controller preferences.

## Approach

Use a dedicated Codex gateway provider and explicit credentials. Apply the requested models and Standard speed to Factory delegation, with user-authorized per-run overrides.
