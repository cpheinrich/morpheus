## Context

Discovered during MO-26-10-24-23.13.37 / PR #499. At head
0015db33fe57acbac408d466c50c772d994eff1b, `morpheus wait-ci 499` reported green
(10 checks: 7 passed, 3 skipped) after run 40179926816 succeeded, while the
same-head ready-event run 40179927140 had a failed Node check and pending browser
check. A direct GitHub rollup showed BLOCKED and prevented premature merge.
This is separate from CI path selection; no waiter implementation changes in #499.
Evidence: https://github.com/cpheinrich/morpheus/actions/runs/40179926816 and
https://github.com/cpheinrich/morpheus/actions/runs/40179927140.

## Approach

Reproduce selection using captured same-head duplicate-run/check fixtures and
inspect the waiter's run/check aggregation. Define which current attempts are
applicable; never substitute a successful duplicate for an applicable failed or
pending check, and do not retain superseded attempts after a successful rerun.
Preserve explicit skipped/required-only behavior and bounded waiting. Add regression
cases for reversed ordering, mixed success/failure/pending, reruns and missing
required statuses. Prove final output agrees with the applicable GitHub conclusions.
Claim and implement in its own worktree and reviewed PR.
