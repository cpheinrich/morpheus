## Context

`morpheus` was never on the PATH. Everything worked via `node dist/cli/index.js`, so the gap was
invisible until Chris ran it from Evo and got `command not found`.

Two causes, both silent:

1. **`npm link` was never run** — the README described it as a future step rather than setup.
2. **`tsc` does not preserve the executable bit**, so `dist/cli/index.js` was unrunnable after
   every build despite its shebang. Fixing only the first would have broken again on the next
   build.

## Fix

`build` now chmods the binary. README documents install as clone → install → build → `npm link`,
plus `morpheus registry add` per project.

## Note for init

`init` cannot assume the CLI is on the PATH of a machine it has never run on — a fresh clone by a
collaborator will not have it. A scaffolded project's `AGENTS.md` must say how to get it.
