## Context

The normal repair verifier rejects an exact reviewed and merged repair because GitHub
retains three unstarted cancelled CI jobs beside their newer successful replacements.
The native repair remains owned by its existing controller; this item changes only
Morpheus source. Runtime adoption and actual delivery remain separate evidence.

## Approach

Keep the strict gate for genuine failures, pending/unknown and external checks. Discharge
only an unstarted GitHub Actions cancellation through exact check/job/run joins, the
latest same-context successful SourceCI run and unambiguous job identity. Read complete
same-head workflow inventories, including runs without checks, then reacquire a stable
bounded view. Retain resolved workflow provenance; floated refs may legitimately advance.
Do not support same-run rerun supersession in this narrow change. Test retained provider
data and refusal boundaries, independently review, then protectively merge with actual CI.
