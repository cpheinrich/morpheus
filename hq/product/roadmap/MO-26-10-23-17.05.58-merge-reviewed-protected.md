## Context

Morpheus #376 had a complete independent review and passing checks but the GitHub Manager
escalated its incidental changes under `src/paths.ts` and `src/review/`. Those prefixes are
protected because the Manager must not approve changes to its own review rules. The remediation
was a normal author-owned PR, not a Morpheus Security App PR.

## Approach

Keep protected paths and the Manager's self-review ban. Add an off-by-default Manager policy
option that lets the deterministic apply step use a verified author review when the Manager
session requested its own review but pushed no commits or PR body change. Opt Morpheus in only;
Lakina and Evo retain their current Manager policy. Drafts and explicit human decisions remain
held, and Morpheus Security stays dependency-only under its existing config. Validate the live
head review, test the refusal boundaries, and document both policy files and precedence.

## Approval boundary

This draft proposes persistent Manager finalization authority in Morpheus. It must not be merged
or activated before Chris confirms the exact effective permissions and risks in the PR. No
branch protection, Security App permission, credential, trading, or deployment rule changes.
