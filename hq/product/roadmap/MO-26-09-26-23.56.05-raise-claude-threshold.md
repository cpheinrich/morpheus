## Context

A 20% Codex allowance reserve can leave too little room for supervising Claude while
other active Codex chats continue consuming the shared allowance.

## Approach

Raise the optional Claude bridge default to 30%, preserve explicit saved thresholds,
and document the strict below-threshold handoff. Routing remains off until enabled.

## Acceptance

- Fresh settings use 30%; automatic routing delegates below 30%, but not at 30%.
- Existing saved 20% settings retain their value and boundary behavior.
- Documentation agrees with the default.
