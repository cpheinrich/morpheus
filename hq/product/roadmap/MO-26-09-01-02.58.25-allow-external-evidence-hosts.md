## Context

GitHub's normal CLI and API can edit pull requests but cannot create the special user-attachment
URLs accepted by the first visual-evidence gate. That makes a browser session an unnecessary
dependency for otherwise autonomous agent delivery.

## Approach

Keep GitHub attachments as a zero-configuration default, and let a repository declare narrowly
scoped public HTTPS prefixes for evidence it owns. Validate the prefix shape in the manifest and
match URL origin plus path without fetching media, so the gate remains deterministic and does not
implicitly trust sibling buckets on a shared provider.
