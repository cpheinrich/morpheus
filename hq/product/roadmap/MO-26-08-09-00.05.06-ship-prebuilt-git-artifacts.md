## Context

Runtime kit modules are intentionally consumed as `github:cpheinrich/morpheus`, not from a package
registry. The package currently builds TypeScript in `prepare`, so pnpm 11 refuses a fresh install
unless each consumer allowlists the exact resolved codeload URL. That duplicates the lockfile SHA,
breaks moving refs, and makes every application build compile the whole Morpheus repository.

## Approach

Commit the platform-independent `dist/` output and remove every manifest field that makes npm or
pnpm prepare a git dependency. Rename Morpheus's contributor build command to `compile`, update its
workflows and docs, and make CI rebuild then fail on any uncommitted artifact drift. Verify both
pnpm 11 and npm consumers against the pushed branch without `allowBuilds` or lifecycle-script
approval.

## Acceptance

- A fresh pnpm 11 project installs the git dependency without `allowBuilds`.
- A fresh npm project installs the same git ref without rebuilding Morpheus.
- Package exports and the CLI resolve from the installed prebuilt artifacts.
- A clean checkout contains `dist/` before any compile command runs.
- CI fails when `src/` and committed `dist/` disagree.
- The package remains private and no registry or release credential is introduced.
