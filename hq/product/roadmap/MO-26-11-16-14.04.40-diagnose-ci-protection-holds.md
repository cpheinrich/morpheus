## Context

Issue #723 reports that current-head required checks can pass while GitHub protection still blocks merge. It also reports an immediate post-rerun wait returning the previous completed attempt.

## Approach

Keep the existing CI verdict. Surface a diagnostic when GitHub reports a blocked merge after required checks pass, and make it possible to wait for the explicitly expected attempt of a workflow run.

## Acceptance

- A green required-check verdict remains green when GitHub reports a blocked merge, with a concrete advisory that distinguishes the two states.
- An explicit expected rerun attempt ignores a stale terminal observation from the previous attempt within the existing timeout; default run waiting remains compatible.
- Test the grounding of the advisory and old-to-new attempt observations without real workflow mutations.
