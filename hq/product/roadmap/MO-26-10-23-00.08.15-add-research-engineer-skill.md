## Context

On 2026-10-23 Chris asked for a "Research Engineer" persona and skill, the first
individual-contributor skill under the agentic-CTO skill (MO-26-10-21-19.17.32). He had been
repeating the same research prompts to agents doing ML and algorithm work — a time-boxed
literature review, benchmark first, rounds of experiments — and wants them built in. The skill
text was distilled in a separate session from a mining report of 152 cited items across Evo and
Codex sessions and records; its provenance paraphrases the private sources.

## Approach

Hold and distribute it exactly as `agentic-cto` is: canonical files in
`.agents/skills/research-engineer/` with a byte-identical `.claude/skills/` mirror; the same
generator writes both skills into `src/cto/skill.ts`; `morpheus cto guide research-engineer`
prints the entrypoint and `morpheus cto guide research-engineer/<reference>` a reference, with
the CTO's own topics unchanged; `morpheus init` writes a one-file pointer for both providers in
every project kind. The CTO skill names it in its delegation rules, with a provenance row.

## Acceptance

- `morpheus cto guide research-engineer` prints the canonical `SKILL.md` and the commands for its
  references; `research-engineer/record` and `research-engineer/provenance` print those files
  byte for byte; `morpheus cto guide`, `mandate` and `provenance` print what they did before,
  apart from the one added CTO rule and its provenance row.
- The canonical files, the Claude mirror and the CLI module agree, and the research engineer's
  `../agentic-cto/SKILL.md` link resolves in both provider directories — enforced by tests.
- `morpheus init` writes the pointer to both provider directories in every project kind, with the
  canonical description, and re-running `init` adds it to an existing project without
  overwriting local edits.
