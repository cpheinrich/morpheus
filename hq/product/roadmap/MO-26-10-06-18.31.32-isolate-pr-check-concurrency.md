## Context

Morpheus Security's validated PR #340 has a successful `Review metadata / pr / conventions`
check, but an older cancelled `CI / pr / conventions` check is also marked required. Both callers
share the reusable job's concurrency group for the PR ref. Metadata updates can therefore cancel
the CI gate and leave GitHub's merge state blocked even after the bot's own checks pass.

## Approach

Scope the reusable job's concurrency group to the caller workflow as well as the PR ref. Keep
same-caller superseded runs cancellable, test the exact group, and verify a fresh bot candidate
can pass GitHub branch protection without bypassing it.
