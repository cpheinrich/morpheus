## Context

The GitHub Manager has run on Evo since 2026-10-05, and decisions.md (2026-10-01) planned Lakina
and Morpheus next after a watch period. Morpheus has the same stall pattern the manager exists for:
pull requests whose authoring session ended before the review loop did. Morpheus is also the
manager's own engine and the source of every project's reusable workflows, templates and review
contract, so it needs a policy that keeps the manager from clearing changes to itself.

## Approach

- Add `.github/morpheus-gh-manager.json` with `version: 1` and `protectedPaths` for the manager's
  engine (`src/gh-manager`, `src/cli/gh-manager.ts`, `src/cli/check.ts`, `src/review`) and for
  what other projects inherit (`src/init/templates.ts`, the review and manager runbooks). Workflows
  are already normative. `sessionBeforeMerge` stays off: authors here merge their own work.
- Add `.github/gh-manager-prompt.md`, written from AGENTS.md, decisions and learned: lead with
  "What makes a test count", the compile/dist gate, reusable-workflow risk, and escalate any change
  to the manager itself.
- Extend AGENTS.md's GitHub Manager section with the policy and overlay pointers.
- Out of scope, done in the operations repository after merge: install the App and add the
  repository to `config/repositories.json`.
