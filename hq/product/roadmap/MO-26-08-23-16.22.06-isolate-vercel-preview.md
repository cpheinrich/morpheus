## Context

Kairos's first shared call was rejected before any step because its existing `Preview` GitHub
environment only allowed `main`, a policy inherited from the former `pull_request_target` flow.
Reusable callers cannot assume that a generic environment name has compatible branch rules.

## Approach

Give preview and production environment names independent inputs and use `Vercel Preview` as the
preview default. That name is specific enough to avoid colliding with project history while still
publishing the exact deployment URL as a GitHub environment receipt.
