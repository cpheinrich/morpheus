## Context

GitHub regenerates PR merge refs when trunk advances without updating the triggering event's
base SHA. The native scope gate then rejects valid merges before compilation (#298, #313).

## Approach

Verify that the actual base descends from the event base while retaining the exact event head
and two-parent merge checks. Fetch ancestry for scoped PRs, compare against the actual base,
and report diagnostic failures. Regression fixtures execute the workflow shell against real
Git histories, including a docs-only PR after native trunk changes and an unrelated base.
