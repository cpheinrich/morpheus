## Context

Morpheus recompiles the same file patterns for every path. On Evo, that took 158 ms per
source classification in a local paired probe. A fresh linked checkout also rebuilds
an index when the primary checkout already has one for the same indexed files.
See [the original warmup](../../../.agent/worklog/2026-11-09-warm-context-index.md).

## Approach

Compile glob matchers before classifying paths. Warm the primary trunk through the
existing managed Git update hook and reuse its immutable index in linked worktrees
only when the existing content fingerprint matches. Keep the copy and its lock files
inside the task checkout.

## Acceptance

- The normal MCP search and coverage tools honor the same default and project globs.
- A fresh linked worktree with identical indexed files returns the primary index's
  results and records a cache hit with no build. A change outside the corpus still hits.
- An edited, added or deleted indexed record gets a worktree index with current
  citations. The primary checkout's cache and results are unaffected.
- Verify the compiled MCP from real Git worktrees and require CI and independent review
  before merge.
