## Context

Chris requires a short Zoe group text for every current meeting note. The shared gate currently
blocks that notice until a separate action-promotion change is complete, so a fully verified note
can remain unannounced. The public Morpheus test fixture also contains real project topology and
collaborator addresses that belong in private project profiles, not reusable public machinery.

## Approach

Allow the delivery journal to declare actions either recorded or not yet promoted; preserve the
verified-note, projection, digest, URL, authorization and idempotency gates, and make the formatted
notice state the action status. Replace meeting-intake fixtures with synthetic organizations,
identities, domains and notification targets. Document the public/private boundary, update both
provider skills and scaffold output, and retain focused regression tests for all notice states.
