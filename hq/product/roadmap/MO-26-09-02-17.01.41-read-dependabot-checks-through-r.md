## Context

The first all-PR cloud dry run failed before triage because GitHub's Actions token could not expand
`statusCheckRollup` through `gh pr view`; GraphQL returned “Resource not accessible by
integration” for workflow-run fields. The same query works with a user's CLI token, so the local
dry run did not expose the permission mismatch.

## Approach

Read the authoritative pull-request record, latest check runs, and combined commit statuses through
their narrower REST endpoints. Collapse each check context to its latest observation and preserve
the fail-closed rule that an absent check list is not passing.
