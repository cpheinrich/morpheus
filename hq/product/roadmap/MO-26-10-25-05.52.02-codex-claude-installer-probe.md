## Context

The codex-claude installer probes the installed MCP servers by counting their
advertised tools. The main server now includes pool tools as well as the Claude
tools, so its valid 20-tool contract fails the stale nine-tool count check and
prevents an otherwise current personal installation.

## Approach

Derive the probe's expected tool names from the same registrations used by each
server, compare exact name sets with useful diagnostics, and cover both the
current server contracts and a missing-tool failure. Verify the package tests,
checks, and a real personal installation from this branch.
