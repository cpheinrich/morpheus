## Context

The plugin refused Codex Desktop 0.157 even though the transcript and memory contracts it
consumes were unchanged. Exact version allowlists turn every compatible Codex release into
an outage and prevent the plugin's doctor command from verifying the actual capabilities.

## Approach

Gate detached-task metadata on the fields and permission invariants the bridge consumes,
and gate per-task memory lookup on the SQLite schema. Preserve fail-closed behavior for
missing, malformed, stale, or restricted metadata. Cover arbitrary future version strings
and absent contracts in tests, update compatibility documentation, then exercise the
installed plugin against the current Codex Desktop release.
