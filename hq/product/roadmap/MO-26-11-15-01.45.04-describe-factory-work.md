## Context

Opaque Factory task IDs make Work hard to scan. Operators need to recognize an active or recent task and open its exact evidence.

## Approach

Store opt-in HQ display copy with Fleet tasks, project safe Work metadata from Firestore, and share the same display and links through the Infrastructure desk package. Keep data access and branding with each desk.

## Acceptance

- The shared desk display rules use a short, explicitly supplied human title and keep the
  task ID for the detail view. Legacy tasks have a readable fallback and no fabricated summary.
- Fleet stores viewer-safe display metadata separately from prompts and messages and
  identifies exact repository commits and PRs when known.
- A project-specific, read-only viewer can read bounded active and recent Work rows. The
  response contains no briefs, conversations, raw worker output, or data from other projects.
- Darwin and Lakina adopt the same presentation. Lakina enables the source only once its
  project-scoped viewer enrollment is verified.
