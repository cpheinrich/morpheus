## Context

Comment QA worked for iOS apps (MO-26-10-06-15.17.01). Chris asked (2026-10-06) for the same on a
local website, as soon as possible: run the site, pin comments on it, have any agent act on them.

## Approach

- `morpheus qa preview web start|status|stop|help`, declared by `morpheus.json` `qa.web` (dev
  server url, the command that starts it, its directory, the first page). Attaches to a running dev
  server or starts and owns one, under the same launchd lease as the iOS preview.
- The overlay is a reverse proxy that injects a script into each page: a shadow-DOM toolbar with
  element-anchored pins, whole-page capture with modern-screenshot, and the shared batch writer, so
  web batches land in the same inbox in the same schema (anchors gain optional `element` and `page`).
- The guide and the `comment-qa` skill cover web; every agent opens the printed overlay URL.

## Acceptance checks

- On the real Lakina site: start (spawning the dev server), the page renders with the toolbar and no
  hydration error, hot reload works through the proxy, a gated route's redirect stays on the overlay,
  right-click and Comment-mode pins, a batch with element anchors and a faithful full-page frame,
  resolve, status, stop ending the dev server it started, and attach mode leaving one it did not.
