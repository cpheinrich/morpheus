## Context

Run the 2026-11-02 codebase-wide technical-health review against current `origin/main`. Keep
coherent, high-confidence, low-blast-radius cleanup on this audit branch, isolate dependency or
other disruptive remediation in focused draft pull requests, and make current security,
structural, test, CI, and governance evidence reviewable without duplicating open work.

## Approach

Refresh repository and remote context; inspect dependency, dead-code, asset, duplication,
complexity, test, CI, and governance health; implement safe cleanup; validate proportionately;
and publish the dated audit report. Reuse open focused remediation pull requests when they remain
the right vehicle, leave every pull request open with auto-merge disabled, and stop at fresh
independent review.

## Mandate

- Acceptance: a marked, non-draft audit pull request with a dated executive summary and ranked
  findings carrying evidence, confidence, impact, and next action; current low-risk cleanup
  implemented and validated; larger findings isolated in existing or new focused drafts; fresh
  independent review and exact-head checks visible; all pull requests left open without
  auto-merge.
- Authority: change this governed audit branch and refresh or open focused remediation branches
  and pull requests. Do not merge, enable auto-merge, close work, deploy, dispatch workflows,
  create credentials, access live production data, or bypass roadmap, claim, review, or CI
  controls.
- Budget: existing local agent subscription and included CI only. No spend or paid service is
  authorized.
- Reporting: report milestones, precise blockers, and completion; unchanged state is not a
  milestone.
- Stop: acceptance or a precisely evidenced blocker after safe alternatives are exhausted.
