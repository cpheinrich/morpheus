## Context

The root production graph installs `@modelcontextprotocol/sdk@1.31.0`, which is affected by two
high- and two moderate-severity advisories fixed in 1.32.0. The weekly audit found no current open
root remediation vehicle; Factory's separate draft cannot own the root graph.

## Approach

Upgrade only the root MCP SDK line to 1.32.0, regenerate the root lockfile, exercise the root MCP
server/client contract, and verify that the four SDK advisories leave the production audit. Keep
the remaining Zod and minimatch advisories isolated in their existing drafts.
