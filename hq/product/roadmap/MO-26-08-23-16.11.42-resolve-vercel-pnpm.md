## Context

The first live Evo caller failed before deployment because the reusable workflow looked for
`packageManager` in `apps/web/package.json`, while Evo correctly pins pnpm in its monorepo root.
Kairos has the inverse layout and pins it in the app manifest.

## Approach

Add an explicit package-manager manifest input, default it to the repository root for monorepos,
and let app-only repositories override it without specifying a second pnpm version.
