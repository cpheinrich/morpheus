## Context

The project-wide lease serializes Git-backed tasks even when each attempt makes an isolated checkout. Additional enrolled workers need to execute independent tasks concurrently.

## Approach

Allow an operator to opt an isolated single-repository Git enrollment into per-task leases. Keep fixed and related workspaces on their shared lease and preserve protected cleanup and authorization. The operator uses independently configured slots in the existing service.

## Acceptance

- Four independent tasks can claim separate slots on one host and settle with exact cleanup.
- Existing task records and stable submission replay preserve their original lease and eligible slots. A changed submitted action is rejected.
- Invalid workspace enrollment cannot opt into the isolated path.
- Verify the protected rollout and four live slot receipts before reporting the requested capacity.
