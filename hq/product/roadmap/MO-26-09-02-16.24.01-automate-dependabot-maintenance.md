## Context

Dependabot changes are currently rejected by human-author PR conventions, and each consuming
repository would otherwise have to recreate the same privileged workflow. The automation must not
give a probabilistic reviewer both the OpenAI credential and authority to mutate pull requests.

## Approach

Ship a reusable workflow and a tested policy engine. Recognize only the exact Dependabot App and a
narrow dependency-file allowlist; apply project policy first; run Codex read-only only for
unmatched changes; and deliver through a separate job that revalidates live state. Document the
CI-completion plus nightly-reconciliation trigger contract and make genuine Dependabot-only PRs an
explicit, visible convention waiver.
