## Context

Chris asked to pause agent pull-request review on Morpheus for now without removing the CI flow.
`agent-review / delivery` is a required status check, so disabling the caller itself would leave
that nested check unreported and block every pull request instead of merely skipping review.

## Approach

Add an enabled-by-default input to the reusable workflow and evaluate it on both reported jobs.
Set the input to `false` in Morpheus's automatic and on-request callers, leaving consumer defaults,
credentials, permissions, workflow structure, and branch protection intact. Test the input and
both caller overrides, then verify the resulting pull request reports the delivery check as
skipped and remains mergeable.
