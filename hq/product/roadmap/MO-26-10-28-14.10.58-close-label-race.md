## Context

`conventions` fails a ready PR that lacks `agent-reviewed` until the review is recorded and the
label applied. The documented route around it — open with the label, or as an unlabelled draft,
which waits instead of failing (`docs/runbooks/independent-review.md`) — helped take conventions
failures per PR from 65% to 14% on Morpheus and from 88% to 24% on Evo between 2026-09-24→10-07
and 10-09→10-22 ([worklog](../../../.agent/worklog/2026-10-28-profiling-round-2.md)).

The race persists for PRs opened ready. In a sample of 13 Evo label-race failures after 10-08, 6
came from robbie-del's branches, written by Cursor and Claude setups that do not load Morpheus's
instructions the way a Morpheus-launched Claude or Codex session does. A rule those agents never
read cannot be followed.

## Approach

1. **Draft by default wherever Morpheus prints a PR-opening command.** `review prepare`, the
   `check pr` failure text, `wait-ci`'s label-race digest line, the scaffolded `AGENTS.md` template
   and the runbooks lead with `gh pr create --draft` and `gh pr ready` once the record lands;
   `--label agent-reviewed` stays the form when the record is already committed. Trunk rescue
   already opens drafts.
2. **Reach the agents that do not read `AGENTS.md` through Morpheus.** Establish what robbie-del's
   Cursor and Claude setups load in Evo — Cursor project rules, `AGENTS.md` support, a user-level
   `CLAUDE.md` outside the repository, or nothing — by asking him rather than inferring it. Then
   make `morpheus init` and `context install` write whatever pointer each needs so the same rule
   reaches them.
3. **Make the remaining race legible.** When conventions fails only on the missing label, on a
   ready PR with no review record, say so with the exact `gh pr ready --undo` command instead of a
   generic failure. Keep it failing; whether to soften the check itself is a separate policy
   question.
