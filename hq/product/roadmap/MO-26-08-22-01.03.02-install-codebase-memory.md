## Context

Morpheus requires graph-first structural code discovery, but that convention currently assumes a
device already has `codebase-memory-mcp`, a configured agent client, automatic index maintenance,
and a graph for the exact checkout. A missing tool or a sibling-worktree index silently sends an
agent back to slower search or, worse, stale structural evidence.

## Approach

Add an explicit, idempotent trusted-device command that uses a reviewed package pin when the
native binary is absent or mismatched, delegates client configuration to the upstream installer, enables
automatic indexing and watching, fully indexes the exact checkout, and verifies the graph's Git
SHA against `HEAD`. Make `--check` read-only, surface the same drift through `doctor`, document the
security and freshness boundary, and scaffold the check into every new Morpheus project.
