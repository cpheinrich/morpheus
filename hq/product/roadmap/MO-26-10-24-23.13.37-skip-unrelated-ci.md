## Context

The Paperclip overview documentation PR ran the macOS Claude bridge, browser QA and
artifact transport checks despite changing none of their inputs. Chris requested
scoped CI in a separate PR, preserving PM and PR conventions, and an explanation
of whether the two Python artifact matrix legs need separate uploads.

## Approach

Classify the complete PR diff with a small native Git/Node selector. Skip expensive
jobs only after a verified irrelevant comparison; unknown paths or unavailable
comparison run all. Keep PM/PR checks independent and retain the required nested
`node / check` name by skipping inside its reusable workflow. Main pushes run all.
Keep Python 3.9 and 3.14 filesystem/environment coverage on one runner, followed by
one fixed Node 24 artifact transport/readback. Validate real Git histories, parsed
workflow conditions, both Python interpreters and actual GitHub check reporting.
