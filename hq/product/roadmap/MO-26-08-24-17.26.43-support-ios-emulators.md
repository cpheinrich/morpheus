## Context

Kairos's first native CI suite needs Firebase Auth and Firestore emulators plus a seeded Auth
fixture, while Evo's native suite is self-contained. Keeping Kairos's full macOS workflow as a
project-local copy would duplicate the runner, Xcode selection, SwiftPM cache, build/test split,
and result artifact policy that Morpheus already owns. The reusable workflow needs one explicit,
opt-in service seam so both apps can delegate without making Firebase a requirement for every iOS
consumer.

## Approach

Extend `ios-ci.yml` with disabled-by-default, secret-free Firebase emulator inputs and an optional
repository-relative pre-test fixture script that runs only after the emulators are live. Keep
caller-provided values out of shell source, validate paths and versions, disable automatic package
resolution after the locked resolve, default parallel testing off for deterministic UI runs, and
export XCTest attachments on success or failure. Pin the public contract with workflow tests and
prove it with thin Kairos and Evo callers.
