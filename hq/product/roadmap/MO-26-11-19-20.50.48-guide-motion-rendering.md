## Context

For a selected motion concept, implementation medium affects fidelity, responsiveness and runtime cost. Ask the user about that choice when it is still open.

## Approach

Update the canonical motion-design skill and its byte-identical scaffold copy. Cover native drawing and shaders, pre-rendered frames, intended-size validation and Reduce Motion. Preserve explicit choices and project-owned skill copies.

## Acceptance

- The exploration guidance asks about the production rendering approach only when the user has asked to build and has not selected a medium.
- The exact canonical guidance is distributed by the CLI scaffold; existing project-owned copies remain safe to reconcile in their own reviewed changes.
