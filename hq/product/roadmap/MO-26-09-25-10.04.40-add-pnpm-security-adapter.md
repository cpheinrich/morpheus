## Context

Morpheus Security is a general-purpose automation and should have a narrow public repository and
release boundary of its own. Evo requires pnpm delivery, while Morpheus should retain only the PR
policy code that recognizes the bot contract.

## Approach

- Opt into the centrally operated standalone workflow through the App installation, reviewed
  allowlist, and committed repository policy.
- Remove the duplicated reusable workflow, resolver script, and tests now owned upstream.
- Configure the four live protected checks and the private same-installation incident ledger.
- Retain the PR-policy constants and waiver checks that are part of Morpheus governance.
