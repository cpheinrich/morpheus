## Context

Factory currently reads the first subscription per provider, so a second account can leave a usable pool incorrectly refused.

## Approach

Read every eligible subscription in each provider pool. Compare providers using the roomiest known account and let sub2api schedule requests within the selected pool. Honor explicit model requests when picking the worker.
