## Context

Task worktrees have accumulated under `~/code`, both as visible sibling folders and in
`.morpheus-worktrees`. Finished PRs leave those checkouts behind, making the source folder
hard to navigate and consuming disk. Chris asked on October 13 to use a temporary location
for new worktrees and clean each one after its work is merged.

## Approach

Allocate new task worktrees under the OS temporary directory while continuing to resume
existing worktrees wherever they live. Add an explicit cleanup command that verifies an
exact merged PR, branch ancestry, current trunk, and a clean unlocked checkout before
removing the worktree and obsolete refs. Preserve unfinished local data and provide a
read-only inventory for older worktrees. Document cleanup as the author's post-merge step.
