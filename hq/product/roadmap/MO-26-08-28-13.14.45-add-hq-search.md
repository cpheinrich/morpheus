## Context

Darwin now has a working, build-time HQ search over Markdown and text-based PDFs, and Lakina is the
second real consumer. Keeping the engine, index contract, extraction rules, and interaction shell in
each repository would make fixes drift. Morpheus already defines `morpheus-kit/hq` as the reusable
runtime boundary, and this is the second-use extraction trigger.

## Approach

Add a framework-light `morpheus-kit/hq-search` subpath with the document/index contract, MiniSearch
engine, deterministic snippets and ranking, Markdown/PDF extraction helpers, private-cache response
headers, and a configurable accessible search dialog. Keep project-owned auth, HQ catalogue routing,
and brand tokens in each consumer. Ship committed `dist/`, unit/component tests, architecture docs,
and prove the package in Darwin and Lakina before calling the extraction complete.
