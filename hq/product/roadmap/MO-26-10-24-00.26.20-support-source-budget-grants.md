## Context

Native CD admission has a configured ceiling of at most $250. Separately reviewed,
finite source-publication work needs an explicit administrative reservation route
without changing native admission, the stored configuration identity, existing
obligations or controller behavior. A request received in chat still follows the
normal claim, source review, CI and protected-merge lifecycle before use.

## Approach

Add a narrow source-finance module and opt-in flags only for `cd budget reserve`.
Strict reviewed grant/request snapshots bind the exact source namespace, target,
epoch, both configuration digests, amount, aggregate ceiling and short expiry.
Use the existing owner-bound GitHubStore, preflight before replay, fresh checks at
every CAS callback and complete receipt readback. Preserve the absent-authority
native path. Cover generic values and counterexamples with hermetic public CLI,
file-input, CAS, replay, owner, lost-reply, expiry and overflow tests. Update the
operator contract, architecture and generated distribution before independent review.

The implementation is locally prepared for review. Publication, CI, independent
review, merge and any actual grant use remain pending.
