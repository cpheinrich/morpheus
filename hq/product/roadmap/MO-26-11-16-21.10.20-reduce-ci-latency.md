## Context

Chris asked which of five CI speed ideas from a November 15 tweet (a faster type checker, Oxlint, time-balanced test shards, running only tests reachable from the diff, and parallel lint/typecheck/build/test) actually shorten Morpheus pull-request CI, with evidence before any rollout to other projects. The required `node / check` is the whole critical path: about three minutes, of which the tests are 90–135 seconds and the serial steps around them 40–60.

## Approach

Measure before changing: per-step timings from recent Actions runs, then each idea against this repository. Pilot only the smallest change the numbers support, on Morpheus alone, behind a default-off `node-ci.yml` input so every `@main` caller keeps today's steps. Typecheck, lint, the context-runtime install and the verified build run concurrently in the existing required job before the tests. Record the evidence for all five ideas, the rollout order and the revert path in [`docs/ci-speed.md`](../../../docs/ci-speed.md).

## Acceptance

- `node / check`, `pm / pm`, `pr / conventions` and `agent-review / delivery` keep their names and their success, failure and skipped reporting; no branch rule, runner, schedule or credential changes.
- The full suite, lint, typecheck and committed `dist/` verification still run on every Node-scoped pull request and every main push.
- Callers that do not set the new input run the same steps and scripts as before.
- Comparable Actions runs show the required-check time before and after.
- Each of the five ideas has a recorded verdict with its measurement.
