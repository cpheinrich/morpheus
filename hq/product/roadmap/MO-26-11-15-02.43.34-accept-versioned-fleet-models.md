## Context

Fleet used the routing ID grammar for Codex model names. A versioned model such as `gpt-6.1-sol` prevented the enrolled service from starting.

## Approach

Use one model-name schema across service startup and both submit interfaces. Preserve exact enrollment matching and the existing routing ID rules.

## Acceptance

- The Fleet service starts with a versioned Codex enrollment.
- A default request and an explicitly matching versioned model select the exact same model.
- An explicit mismatch, malformed name, or malformed routing ID is rejected.
