## Context

PR #341 separated `CI` and `Review metadata` cancellation groups, but the fresh bot PR #346
still had a cancelled `Review metadata / pr / conventions` job marked required by GitHub after
a burst of label events. A later successful metadata run and a successful CI conventions run did
not clear the merge block. The bot therefore still needs a manual rerun before it can merge.

## Approach

Remove concurrency from the reusable required-check job. Keep both callers free of concurrency
groups so each current-head run finishes. Test all three workflow surfaces and verify a fresh bot
candidate becomes mergeable without a manual rerun.
