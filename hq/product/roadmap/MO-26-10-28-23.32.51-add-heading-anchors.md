## Context

Chris, 2026-10-28, in a Lakina session: hovering any section header in an HQ page — major or
minor — should show a link icon in the left gutter, and clicking it should copy
`page-url#section`, so a specific section can be shared. He asked for it at the design-system
level rather than page by page, and at the Morpheus level if possible so every project gets it,
with retroactive coverage of existing pages. Choices he made: `h2`–`h4` (not the page title);
copy and update the address bar; ship in Morpheus and wire into every consuming project now.

## Approach

`morpheus-kit/section-links` (framework-free helpers) and `/react` (`<SectionLinks />`), mounted
once in the HQ layout. It gives `h2`–`h4` without an `id` GitHub's slug of their text, leaves
authored ids alone, and shows one floating icon beside the hovered heading or its gutter. Clicking
copies the address and `replaceState`s it. The generated HQ layout template mounts it. Consuming
projects (Lakina, Darwin, Kairos, Evo, cpheinrich.com) adopt it with a kit bump and one line in
their HQ layout, in their own PRs.

## Acceptance

- Hovering an `h2`–`h4` in HQ content, or its left gutter, shows a link icon; nav, rail and dialog
  headings get none.
- Clicking copies `origin + path + query + #id`, puts it in the address bar, and adds no history entry.
- A heading with an authored id keeps it; one without gets GitHub's slug, deduplicated.
- Opening a link to a generated id lands on that section.
- `morpheus web init` generates an HQ layout that mounts the component.
