## Context

The opt-in Studio pilot proved remote execution but required a checkout and service enrollment per commit. A phased rollout needs the regular Factory tools and automatic checkout creation.

## Approach

Keep local delegation as the default. A fleet request identifies a clean linked checkout and the enrolled project. The Studio supervisor fetches the exact published commit with read-only repo access. The executor creates an isolated checkout for the attempt.

## Acceptance

- A normal Codex Factory delegation can opt into the fleet and supervise the returned run ID.
- A new published commit for an enrolled repository runs on the Studio without host setup for that ticket.
- The controller drives a real implementation ticket through independent review, required CI and merge.
