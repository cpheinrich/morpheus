## Context

Obsidian writes per-vault UI and plugin state into `.obsidian/`. That machine-local
metadata should not be committed when Morpheus projects are opened as vaults.

## Approach

Add `.obsidian/` to the initializer's Git ignore template, pin the behavior with
an initializer test, and propagate the same ignore line to every registered project.
