## Context

The first live caller produced a valid inspection receipt, but `actions/upload-artifact` excluded
the dot-prefixed `.dependabot-maintainer` directory and failed with “No files were found.” No pull
request was mutated, but the cloud pipeline could not reach triage or delivery.

## Approach

Enable hidden files on the exact artifact path and add a parsed-workflow regression assertion. The
exact path keeps the broader workspace and any unrelated hidden files outside the artifact.
