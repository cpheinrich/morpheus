## Context

The SessionStart hook correctly discards inherited certification without touching the checkout,
but the next explicit context refresh can fingerprint records from a checkout behind the remote
trunk while recording the current remote SHA. After `brief` clears the prior receipt, the refresh
has no baseline from which to display that mismatch and can certify stale source as fresh.

## Approach

Keep SessionStart non-networked and non-mutating. Before a refresh fingerprints records, fetch the
declared trunk and prove its observed SHA is an ancestor of `HEAD`. Fast-forward only a clean local
trunk, then require the agent to re-read and refresh again; refuse dirty trunks, stale feature
branches and divergence without rewriting them. Cover each lifecycle state with real Git tests and
update the canonical architecture and generated instructions.
