## Context

Issue #421 reports that `pm ship <ID> --check` rewrites status and updated dates. The explicit-ID path ignores the check flag, and multiple IDs can partially write before a later unknown ID fails.

## Approach

Reject explicit IDs combined with `--check` before any item write. Document the supported command forms. Keep no-ID merged-PR checks and deliberate explicit shipping intact.

## Acceptance

- One or multiple explicit IDs with `--check` exit 1, print a useful error, and preserve complete file bytes.
- `pm ship <ID>` continues to ship deliberately.
- CLI argument ordering cannot bypass the guard.
