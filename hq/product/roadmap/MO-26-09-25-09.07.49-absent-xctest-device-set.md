## Context

Lakina PR402 passed all app tests, then failed post-cleanup because its fresh serial runner had no Library/Developer/XCTestDevices directory. The worker set is optional when no parallel tests have ever run.

## Approach

Treat only simctl's missing-set diagnostic for the testing selector as empty. Preserve failures for unreadable sets, permission errors, missing default inventory, and actual deletion failures.
