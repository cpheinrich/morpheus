## Context

Since MO-26-10-12-11.30.12 the GitHub Manager skips every draft, `wip/` branch and WIP-titled pull
request indefinitely. Chris chose that so WIP work would not be promoted or merged without input.
On 2026-10-20 he asked for the next step (issue #442): review and triage WIP pull requests instead.
Some are finished and only drafts by accident; some are well specified but incomplete and could be
handed to another agent; some are underspecified, redundant or low value and should be ignored until
someone resumes them. In one consumer's latest run, 16 of 26 open pull requests were skipped this way.

## Approach

Add a triage route for a draft or WIP pull request that has been quiet for `draftQuietHours`
(rescued `wip/trunk-*` drafts keep their escalation). One read-only session decides `ready`,
`incomplete` (a handoff listing remaining implementation and checks), `dormant`, `escalate` or
`wait`. Apply verifies with Git that the session pushed nothing and refuses merge or close. `ready`
marks a plain draft ready for review, after which the unchanged normal path reviews and merges it; a
WIP title or `wip/` branch is reported only. `dormant` adds `manager:dormant`. The verdict is kept in
the comment marker against the head, so an unchanged draft is not reclassified each run; a new push
or removing the label re-triages it. Triage sessions rank after ready pull requests, and
`actions.triage: false` restores the old skip.

## Acceptance

- A quiet draft routes to a triage session; a draft inside `draftQuietHours`, a rescued trunk draft
  and a draft with queued auto-merge keep their current routes.
- A triaged draft is skipped while its head and label are unchanged, and re-triaged after a push or
  label removal; attempts per head are bounded.
- Apply refuses a triage decision when the session pushed anything, and never merges or closes from
  triage. `ready` undrafts only a plain draft under `actions.undraft`.
- Focused tests cover routing, planning, marker parsing and the brief; the runbook, architecture and
  decisions describe the new policy.
