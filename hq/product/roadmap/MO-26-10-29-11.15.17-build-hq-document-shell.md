## Context

The 2026-10-29 Lakina, Darwin and Evo audit found the same document failures in independent
renderers: no reliable executive-brief contract, incomplete heading/fragment behavior, no active
local outline, unbounded sibling navigation, duplicated shell chrome and weak accessibility tokens.
Project-specific patches will keep drifting until `morpheus-kit` owns the shared presentation layer.

## Approach

Build and document the shared `HqShell`, `ExecutiveBrief`, `InPageNav`, `Breadcrumbs` and bounded
`RelatedPages` contracts from `docs/runbooks/hq-product-design.md`. Include skip/landmark and active
navigation semantics, stable same-page fragments, responsive/mobile behavior and accessible text
tokens. Preserve project authorization, route catalogues, content and brand values. Prove the
foundation in Darwin's generic Markdown renderer, then adopt it in a second project before calling
the extraction complete. Add structural checks for fragments, nested main landmarks and unbounded
sibling lists, plus final-build desktop/mobile evidence.
