## Context

Every repository in the registry has moved to `hq/team/` — Morpheus, Lakina, Darwin, Evo,
heinrich.llc, heinrich.money and heinrichbros.com. That was the condition `LEGACY_INBOX_DIR`'s own
doc comment set for its deletion, and it is now met.

The fallback existed because Morpheus migrates first by design while the reusable workflows pin
`@main`, so there was a window where both layouts were live. The window is closed. Left in place it
becomes the worst kind of compatibility code: silent, untriggered, and read by the next person as
evidence that both layouts are still supported.

Two gaps also showed up while migrating. `morpheus init` scaffolds `hq/team/README.md` but no
`meeting-notes/`, so a freshly scaffolded project ends up with *less* than a migrated one — and the
folder the redaction rules protect is the one that does not exist until somebody hand-creates it.
Lakina's migration, done independently, produced no `hq/team/README.md` at all.

## Approach

- Delete `LEGACY_INBOX_DIR` and the fallback branch in `src/cli/inbox.ts`. `No inbox directory at
  <dir>` is the honest error again.
- Scaffold `hq/team/meeting-notes/README.md` in `init`: short, pointing at Morpheus's canonical
  format and redaction rules rather than copying 130 lines into every project.
- Backfill the same two files in Lakina.
