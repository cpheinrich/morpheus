## Context

The 2026-11-16 weekly technical-health audit found that the optional Factory host production
graph pins direct `zod@4.1.12`. `pnpm audit --prod` reports GHSA-mrhx-c7xc-m3w5 as a high-severity
memory-exhaustion advisory and names `4.6.6` as the first patched release. Root Morpheus and the
main Factory runtime already use `4.6.6`; no open pull request owns the host upgrade.

## Approach

Upgrade only the Factory host's direct Zod dependency and lockfile resolution to `4.6.6`, run the
host's focused validation and production audit, and deliver the change as a separate draft pull
request linked from the weekly audit. Do not merge, enable auto-merge, deploy, dispatch workflows,
or change security policy.

## Acceptance

- The Factory host manifest and lockfile resolve direct Zod `4.6.6` without unrelated dependency
  changes.
- The host typecheck, complete package tests, static checks, frozen install, and production audit
  pass; the audit reports no production advisory.
- A governed draft pull request is open and linked from the 2026-11-16 weekly audit.
