## Context

Shorten lint feedback for people and agents across Morpheus JavaScript and
TypeScript projects. The previous pilot measured the Oxlint migration on the
Morpheus source tree and found equivalent diagnostics in its probe.

## Approach

Replace the Morpheus lint script and package with Oxlint and generate an app-local
Oxlint config for new Next.js apps. Existing projects switch independently using
their current CI and package manager.

## Acceptance

- Morpheus lint catches unused declarations and explicit `any` and retains the
  underscore exemption.
- Fresh web scaffolds run Oxlint with their React, Next.js and accessibility
  configuration. A seeded async Client Component fails lint.
- An established app keeps its lint settings when scaffolding adds other features.
- The required Node check runs the new lint script and the full suite.
