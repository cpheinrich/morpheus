## Context

The iOS CI evidence bundle records selected test identifiers but omits skipped
identifiers, so a retained result cannot show which tests the caller excluded.
This was found in the independent review of PR #402.

## Approach

Write the exact `skip-testing` input beside `only-testing.txt` in the same
evidence directory, and assert the export step carries and writes both inputs.
