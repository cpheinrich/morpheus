## Context

Read-only OSV reports repeat known dependency findings without fixing them. Chris requested a
nightly, cross-repository pipeline that turns trusted advisories into separate tested dependency
PRs and merges them without a local Codex heartbeat or paid service.

## Approach

Ship a reusable GitHub Action and private least-privilege `morpheus-security` GitHub App. Combine
active OSV findings with GitHub reviewed alerts, enforce registry/integrity/diff/rescan gates, create
one dependency per PR, and let branch protection govern auto-merge. Record MAL findings in a private
incident issue. Lakina is the first production installation and acceptance run.
