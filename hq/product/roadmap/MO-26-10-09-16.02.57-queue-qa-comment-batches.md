## Context

An Evo Codex QA batch was durably written but the active chat did not wake. A
second batch can arrive while the first is being worked on, and multiple agents
can share Morpheus's QA surface. The queue must preserve every batch and avoid
two responders acting on the same one. Issue #372 also asks for an honest
fallback when the host cannot wake a chat.

## Approach

Publish each batch and optional frame atomically, add exclusive persistent
per-batch claims with explicit release/recovery, and expose an agent-neutral
claim/resolve flow in the CLI and guide. Show the open count and responder
status in both overlays. A single background process owns the checkout and
invokes a configurable agent command for one batch at a time, leaving the
interactive chat free. This uses the agent's CLI rather than a chat wake API.
