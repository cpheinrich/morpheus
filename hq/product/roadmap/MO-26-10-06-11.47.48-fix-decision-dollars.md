## Context

The GitHub Manager's first working run on Evo (ops run 37423690854, 2026-10-06) escalated
darwin-health/evo#341 with a comment that quoted `$429.99` as `29.99`, `$189.99` as `89.99` and
`$199.99` as `99.99`, which were the figures the escalation asked a human to decide on. The
corruption was already in the session's `decision-341.json` artifact, so the apply step and the
digest are not responsible. The session ran with `--dangerously-skip-permissions` and wrote the file
through the shell, where an unquoted heredoc or `echo` expands `$4` and `$1` as positional
parameters. Any dollar figure in any manager comment, on any repository, is exposed the same way.

## Approach

Tell the session to create the decision file with its file-writing tool and never with the
shell, and give the reason in the prompt so the instruction is not read as style. A test pins the
instruction under `## Decision file`. No apply-side check: a lost `$4` leaves no detectable trace
in valid JSON.
