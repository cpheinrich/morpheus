## Context

Every project trusts the globally installed CLI, but the old `npm link` installation made a source
directory part of the runtime. Protecting dirty work by linking a clean worktree therefore made that
temporary worktree undeletable, while a stale install could disagree with canonical CI without any
session-start warning. Issues #111, #121, and #166 are the same missing tool-freshness contract.

## Approach

Install a copied package from one clean exact-main checkout and record its commit. Add explicit
`self check`, `self install`, and disposable-clone `self update` commands; surface drift from
`context brief`, `doctor`, and codebase-memory status without performing background updates. Treat a
package as source only when its own directory is the exact Git root, so an ancestor repository such
as Homebrew cannot satisfy the check.

## Acceptance

- The global package directory is not a symlink and remains runnable after the source checkout is
  removed.
- Current, stale, dirty, ahead, missing-receipt, ancestor-repository, and offline states are explicit.
- Session start and doctor report stale CLI state but never download or mutate source.
- Tests prove the installer uses a disposable clone/copy and never `npm link`.
