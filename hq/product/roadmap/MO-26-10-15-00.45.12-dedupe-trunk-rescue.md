## Context

Evo's Xcode-open trunk generated seven rescue draft PRs in 36 hours, many
with byte-identical project or scheme diffs. The rescue preserved each edit
correctly, but repeated the same PR and human escalation.

## Approach

Compare exact Git diffs, including old/new blob ids, paths and modes, with
locally visible `wip/trunk-*` branches before opening a new rescue. Confirm
that a candidate still exists on the push remote at the same SHA and has an
open GitHub PR; cached remote-tracking refs alone are not enough. Keep network
lookups before the content proof/reset window. A match resets trunk and
reports the earlier PR plus the generator-loop cause; a failed lookup
continues the normal rescue.
