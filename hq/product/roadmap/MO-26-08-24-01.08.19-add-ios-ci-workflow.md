## Context

Morpheus projects can delegate web, Python, Firebase, deployment, and review checks to reviewed
parent workflows, but native Apple clients currently have to invent their own macOS runner,
toolchain selection, package resolution, simulator destination, test result handling, and failure
artifacts. Evo is the second project to need native iOS CI, which is the extraction trigger for a
reusable workflow rather than another project-specific copy.

## Approach

Add a secret-free `workflow_call` contract that selects a current Xcode 26 toolchain, resolves the
caller's checked-in Swift package lockfile without updating it, and runs an explicit iOS simulator
test action with isolated SourcePackages, DerivedData, and result-bundle paths. Keep the project,
scheme, platform, destination, and optional test arguments configurable while making the defaults
fit an iOS 26.5 SwiftUI app. Upload the `.xcresult` and logs when a run fails, document the caller
contract, and pin its permissions, timeout, and concurrency semantics with workflow tests.
