## Context

The merged Factory tool contract deliberately accepts the cross-provider edge efforts `minimal`
and `ultra`. A post-install live Codex-root qualification reached the gateway but the selected
Codex model rejected `minimal`; the root recovered with `low`. A saved configuration created
before this correction does not carry aliases for those values, so installation alone cannot
repair the mismatch.

## Approach

Normalize `minimal` to `low` and `ultra` to `max` at the Codex worker boundary for both Codex and
Claude roots. Preserve all native Codex effort values, saved explicit mappings, permission and
routing behavior. Prove both edge aliases with focused tests and repeat the installed live smoke.
