## Context

Chris asked for a Lakina HQ Infra tab built on Darwin's Operations Desk behaviour, with the
applicable common code lifted into Morpheus and both desks proven afterwards (Lakina
LK-26-11-13-23.29.19). Darwin is the first consumer; Lakina is the second, which is the
extraction trigger ("extract on the second use").

## Approach

Add `morpheus-kit/ops-desk` and `morpheus-kit/ops-desk/react` with the project-neutral display
contract only: compact browser-local times, validated GitHub run/attempt/job/commit/PR links,
dated terminal outcomes versus stale live states, newest-attempt ordering and URL-fragment views
with a history hook. Sources, readers, authorization, copy and pipeline topology stay in each
project. Darwin adopts it without behaviour change; Lakina builds its Infra tab on it.

## Acceptance

- The module and its React hook are exported, documented and covered by focused tests.
- Darwin's Operations Desk imports the shared helpers with its existing tests and browser
  harness unchanged in outcome; Lakina's Infra tab uses the same helpers.
