## Context

The [context audit](https://github.com/cpheinrich/morpheus/pull/716) reproduced three
defects and left a fourth unverified. An agent that passed an overview link to an exact read
was refused, and a long or truncated read did not say where to continue. The profiler named a
task worktree or a Factory checkout after its directory instead of its repository. Traces
recorded that a read failed but not why, and the profile summary dropped the partial flag.
Claude sessions showed no observed excerpts for successful calls.

## Approach

Fix the proven causes in place. The overview lists exact read parameters for local
architecture sections and keeps its links. A read names the next range. A refused read is
traced under a fixed category, and the summary keeps the partial count. Keyed checkouts are
attributed by the repository key in their path. The Claude visibility defect was captured
from a live hook before any change: Claude Code passes a structured MCP result as one JSON
string, which the hook did not decode.

## Acceptance

- An overview section of a local indexed specification opens with the `read` parameters it
  lists. External architecture links are never fetched as record reads.
- A read over 100 lines is refused with the range to use; 100 lines is accepted. A read cut
  short by its budget names a next range that skips no line. Budget, coverage and worktree
  scope are unchanged.
- An undotted Morpheus task worktree and a Factory checkout attribute to their registered
  repository by key, the dotted layouts still parse, and a same-named checkout with a
  different key is not merged into the registered project.
- Read errors carry one of four fixed reasons in the trace. The profile summary reports
  them and the partial count, and still reads older rows. No text, path or session id is
  added to a trace.
- A real Claude Code hook payload credits a byte-verified excerpt and satisfies the startup
  check. Empty, altered, changed-on-disk, failed, out-of-corpus, other-server, oversized
  and other-session results credit nothing.
