## Context

Enrolled hosts can report current work and capacity. A host scheduler also needs a way to expose the jobs it controls, the next scheduled time and the last observed run.

## Approach

Add an optional v1 source for a producer-owned, bounded status document. The reporter reads it without owning or controlling any task. Preserve the producer timestamp and carry only validated task fields and numeric evidence references. The consumer upgrades first and binds the source to an existing enrolled host.

## Acceptance

- Existing v1 reporters continue to work.
- An enrolled reporter can read its configured owner-only task status file.
- Stale or unavailable producer state remains stale or unavailable.
- Unsafe or unbounded fields, timestamps and duplicate identifiers are rejected.
