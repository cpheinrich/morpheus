## Context

Chris no longer uses Nimbalyst and does not recommend it (2026-10-05). The README still suggested
it as the WYSIWYG editor, and `AGENTS.md` justified a heading rule by its rendering.

## Approach

Remove the README suggestion and keep "any editor works". Restate the heading rule in terms of
Markdown renderers generally, since the rule itself still holds. Mark the 2026-07-29 decision as
superseded rather than deleting it. Historical records (`learned.md`, worklogs, inbox archives)
keep their mentions, as records of what happened. The `nimbalyst-local/` ignore line stays: it
prevents an editor's local state from being committed and suggests nothing.
