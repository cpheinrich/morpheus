## Context

On the macOS Tahoe 26 Mac mini, the release keychain below the Actions runner's
temporary directory accepts the distribution certificate and private key and
passes explicit trust verification, but Xcode export cannot resolve that same
identity. This matches Tahoe reports where temporary-directory keychains are
invisible to identity discovery.

## Approach

Create the uniquely named isolated release keychain inside the runner user's
standard `~/Library/Keychains` domain. Continue setting it as the search-list
and default keychain, and delete it on every exit path. Validate with the failed
Evo upload job through archive, export, upload, processing, and group assignment.
