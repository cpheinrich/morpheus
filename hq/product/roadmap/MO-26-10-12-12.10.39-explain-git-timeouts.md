## Context

Issue #333: Node kills a session Git command at 30 seconds before Git writes its own network diagnostic, and the CLI loses the timeout reason.

## Approach

Recognize Node timeout metadata and prepend the deadline, signal and network guidance. Preserve ordinary errors, including max-buffer errors and external termination.

## Acceptance

Actual Node timeout metadata produces an explicit 30-second diagnostic. Successful output and non-timeout error objects/stderr remain unchanged.
