## Context

Profiling round 2 ([worklog](../../../.agent/worklog/2026-10-28-profiling-round-2.md)) found the CI and conventions machinery much improved and
agent behaviour barely moved. The current tranche targets the behaviour gap:

- MO-26-10-28-14.08.05 — Enforce the context protocol in code
- MO-26-10-28-14.09.01 — Extend wait-ci to any workflow run and steer agents off polling
- MO-26-10-28-14.08.43 — Let superseded CI runs pass with a notice instead of failing silently
- MO-26-10-28-14.08.53 — Make trunk-rescue PRs useful or retire them
- MO-26-10-28-14.11.57 — Close profiling measurement gaps: archived Codex sessions and review
  waivers

Without a re-measurement nobody will know which of them worked.

## Approach

Two weeks after the last of the five merges, measure that two-week window with the same
definitions — and the corrected measurement from the gaps item — and compare it with all three
earlier windows (2026-09-24→10-07, 10-09→10-22, 10-22→10-28):

- **Claude and Codex sessions:** `context refresh` per session, receipts taken without reading the
  records, CI polling calls per session, `wait-ci` per session, first-turn context for main
  sessions and subagents.
- **Evo and Morpheus PRs:** conventions failures per PR, superseded-run failures as a share of them,
  label-race failures, review-coverage failures, CI wall-minutes per PR, CI failure rate, p90
  open→merge, trunk-rescue PRs opened and adopted, `manager:needs-human` count, iOS `build.db`
  failures.

Write a worklog entry with the comparison table and a verdict per tranche item — moved, did not
move, cannot tell — and file follow-ups for what did not move.
