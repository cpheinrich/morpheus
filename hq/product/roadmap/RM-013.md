## Context

Multiple people and multiple agents will work on the same project. Nothing today stops two
agents starting the same roadmap item, and the failure is expensive — duplicated work
discovered at PR time.

Explicitly **not** an assignee field. Any person should be able to point any agent at any item;
ownership starts when work starts, not before.

## Approach

**The remote branch is the claim.** Branch names already derive from the item id
(`rm-014-slug`); make that load-bearing.

```
morpheus pm claim RM-014     git ls-remote --heads origin "rm-014-*"
                             → free: create branch, set in-progress, push to stake it
                             → taken: report who and how long ago, exit non-zero
morpheus pm claims           list live claims with branch age and last committer
```

Chosen over a claim field or lock file because it introduces no new concept, the remote
arbitrates across machines with no shared service, and merging the PR releases the claim
automatically by deleting the branch.

The race window between `ls-remote` and `push` is seconds; a rejected push is the backstop.

## Deferred

`hq/status/<person>.md` — one status inbox per human rather than per session, since the point of
the file is a single place to look. Not built yet: with one collaborator it is a directory
containing one file. Trigger to split: **a second collaborator joins a project.**
