## Context

Morpheus names `hq/marketing/seo/` as the home for website SEO but does not currently scaffold
that directory or tell an agent to configure Google Search Console. In practice, agents can often
complete property verification, sitemap submission, issue inspection, and priority crawl requests
through the user's authenticated browser. Treating that work as a human follow-up leaves new sites
undiscoverable for no substantive reason.

## Approach

Scaffold an SEO-specific README for company and personal projects and add Search Console to their
required onboarding checklist. The guidance will make Search Console browser-first, distinguish an
indexing request from indexing, require a dated operating record, and tell an agent that cannot
proceed to ask immediately for the smallest exact prerequisite without requesting credentials in
chat. Record the same operating rule in the architecture and protect the scaffold with focused
tests.
