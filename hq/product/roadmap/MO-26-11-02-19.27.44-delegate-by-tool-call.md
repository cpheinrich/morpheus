## Context

The Factory currently decides at the prompt hook whether every user turn should be sent to a
worker. That makes short interactive work slow, gives the root agent no opportunity to apply its
own delegation judgment, and keys resumed workers to implementation details rather than the root
conversation. The same manager/worker contract also needs to work when either Codex or Claude is
the root agent.

## Mandate

- **Outcome:** expose the Factory as one provider-neutral tool surface that Codex or Claude may
  call, keep one pinned primary worker for the root session, and remove automatic per-prompt
  dispatch.
- **Acceptance:** ordinary prompts remain with the root; an explicit request to use the Factory is
  delegated and an explicit request to stay local is not; both roots discover and successfully
  invoke the same Factory lifecycle; follow-ups resume the pinned provider/gateway session without
  silent rerouting; an explicit fresh worker remains possible; permissions, quota, concurrent
  writer and worktree guards still apply; edit-ownership protection is symmetric; focused and
  integration tests pin the contract; isolated live Codex and Claude CLI sessions each discover
  and use the live gateway; independent review and CI clear; the merged Morpheus CLI and Factory
  plugin are reinstalled and smoke-tested on this machine.
- **Authority:** change the Morpheus Factory plugin, tests, documentation and records; use the
  existing Codex and Claude subscriptions for bounded live qualification; open and merge the PR;
  reinstall Morpheus and the personal Factory plugin after merge. This does not authorize a new
  account, permission grant, API/pay-as-you-go billing, prepaid credits or another paid service.
- **Budget:** existing subscription allowance only, subject to the configured Factory quota
  threshold; no more than twelve successful live model turns across both providers unless a failed
  qualification exposes a distinct defect that requires one bounded rerun.
- **Delegation:** the root owns the design and integration; use bounded read-only design critique
  and one fresh independent implementation reviewer. No concurrent writer may share this
  worktree.
- **Reporting:** report at design lock, local test completion, live cross-provider qualification,
  review/CI, and final reinstall.
- **Stop:** complete only when the merged installation passes post-install discovery and a live
  smoke test, or stop earlier for a hard authorization/credential/quota failure with the exact
  remaining acceptance check recorded.

## Approach

1. Map the current hook, routing, session, tool-contract and edit-guard paths and write the smallest
   symmetric contract that preserves the existing safety boundaries.
2. Replace automatic dispatch with root-selected provider-neutral lifecycle tools and a pinned
   primary-worker binding, retaining compatibility aliases only where they avoid an unnecessary
   migration break.
3. Add boundary tests for routing, persistence, explicit fresh sessions, user precedence, tool
   discovery and symmetric guards, then run isolated live root-agent qualification against the
   installed gateway.
4. Complete independent review, CI and merge; reinstall from merged `main` and repeat discovery
   plus one bounded smoke test.
