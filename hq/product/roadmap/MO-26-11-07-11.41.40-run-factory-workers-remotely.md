## Context

Execution currently runs on the controller host, even when model requests use a remote gateway.
A second execution host can share the same gateway and take work when it has room.

## Approach

Start with the A2A-aligned task contract and the existing desktop entry points. Use a Firestore
mailbox and atomic claims for remote execution, and private object storage for artifacts. Adopt
one worker slot first and verify real supervision and file retrieval from the controller.
