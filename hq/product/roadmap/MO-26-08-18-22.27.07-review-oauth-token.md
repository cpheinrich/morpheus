## Context

Rung 2 burned $243.36 of API credits in eleven days, and the Cost console shows every dollar on
`morpheus-key` — the CI reviewer. $123.91 of it was one day: 55 pushes to one branch under the old
per-push trigger, each buying an Opus review. The trigger is fixed (MO-26-08-17-15.23.36), which
caps the *rate*; this changes what the remaining spend draws on.

Chris's call, 2026-08-18: reviews should bill his Max subscription, which has plenty of headroom,
rather than a prepaid API balance that dies silently when it hits zero. The failure mode is the
argument as much as the money — an empty balance turned the verifier off for six days while every
check stayed green, and the same event on the Max plan is a throttle rather than an outage.

`claude-code-action` supports this natively: `claude_code_oauth_token` is a documented alternative
to `anthropic_api_key`, present at the exact SHA we pin. Chris has minted the token with
`claude setup-token` and set `CLAUDE_CODE_OAUTH_TOKEN` on morpheus and evo.

## Approach

- `agent-review.yml` declares `claude_code_oauth_token` as a second optional secret and passes it
  to the action. **When both credentials are present the OAuth token wins** and the API key is
  withheld, because the action exports whatever it is given and Claude Code prefers an
  `ANTHROPIC_API_KEY` in its environment — passing both would silently keep billing the credits
  this change exists to stop billing.
- `HAS_KEY` becomes true when *either* secret is present, so the unconfigured-rung report stays
  honest for consumers holding only one.
- Both callers in this repo, and Evo's two callers (a separate PR there), pass the new secret.
- The API key stays declared and functional as a fallback — a consumer with only a key keeps
  working, and revoking the key on this org is a decision for later, not a side effect of this.

## Acceptance

- A review runs green on a real pull request with `total_cost_usd` reported and **$0 landing on
  the API Cost console** for that day.
- A consumer passing only `anthropic_api_key` still reviews; one passing neither still reports
  the rung as unconfigured rather than green.
