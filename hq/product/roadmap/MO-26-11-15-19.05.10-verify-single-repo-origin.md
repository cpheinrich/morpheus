## Context

Git-backed single-repository Fleet attempts were isolated without an origin. A worker could open source but Morpheus startup could not resolve or verify trunk.

## Approach

Use the supervisor’s authenticated mirror to fetch the exact admitted revision and observed default branch tip. Reuse the local pinned comparison remote used by related workspaces. Keep the executor detached and the upstream credential in the supervisor account.

## Acceptance

- A Git-backed single-repository attempt can resolve the real default branch, fetch its pinned snapshot, and compare it with the admitted commit.
- Advancing the upstream branch leaves an existing attempt’s snapshot fixed.
- Reopening an existing attempt preserves edits.
- Qualify the existing execution profiles using the installed host runtime and ordinary Fleet admission.
