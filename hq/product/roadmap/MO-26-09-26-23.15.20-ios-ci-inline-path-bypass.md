## Context

Evo needs one required unit-test check that reports success for unrelated changes without building or launching native tests. Event-level path filters leave required checks pending; a separate selector and aggregate defeat the requested simplification.

## Approach

Add an optional Git-pathspec bypass inside the existing reusable iOS job. Verify PR merge parents before comparing, skip every native/evidence step when unrelated, and retain unchanged manual/nightly defaults. Test real Git fixtures for relevant/unrelated changes, renames/deletes, malformed inputs and missing comparison evidence. Evo adopts it in its separate policy PR.
