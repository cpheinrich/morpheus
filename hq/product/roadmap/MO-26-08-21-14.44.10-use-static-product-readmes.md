## Context

Every roadmap status transition regenerated `hq/product/roadmap/README.md`.
Independent agents therefore changed one shared derived file even when their
canonical item files did not overlap, producing avoidable merge conflicts.

The README is not a machine input. Morpheus commands parse the individual item
files, and project `/hq` roadmap views build their lists from the same
frontmatter.

## Approach

Keep the roadmap README as short static folder documentation. Stop generating
or checking a roadmap table, while retaining validation of every item and the
low-churn generated goal and request indexes.
