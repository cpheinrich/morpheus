## Context

The Screen QA toolbar uses white capsules for Review and Exit. Those capsules are hard to read
when a host app supplies a light accent in dark mode. The fix belongs in the shared package.
The release check also needs to make the executed Swift test count easy to find.

## Approach

- Use appearance-aware colors on Review and Exit, preserving their actions and layout.
- Verify both appearances using synthetic simulator evidence.
- Require a non-empty package test result and display its count in CI. Validate the exact package
  candidate on the native Mac runner through the existing private workflow while Morpheus is public.
- Publish a patch tag from the protected merge. Verify downstream adoption in a separate Evo task.
