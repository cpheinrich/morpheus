## Context

An unattended gateway can lose connectivity when its device key requires periodic
reauthentication. The explicit CI/CD and Factory host installers should verify durable
enrollment when operators choose to install Tailscale.

## Approach

Share one macOS installer in the Factory host package. Require an existing authorized device
tag for a fresh login, which sets Tailscale key expiry off by default. Verify the enrolled tag
and expiry in local status. Keep connected devices on their existing identity. The CI/CD
consumer uses the same helper.

## Acceptance

- Factory worker, gateway and CI/CD host setup can opt into the same tagged enrollment.
- A newly enrolled host must report the requested tag and disabled key expiry.
- Read-only checks and reruns preserve existing connections and make no credential writes.
- A supplied one-time enrollment key is read by Tailscale from the operator's file.
