## Context

An enrolled Codex controller needs ordinary Factory delegation to use the fleet unless the operator explicitly requests a local worker.

## Approach

Save a controller-owned placement preference, keep existing installs local by default, preserve explicit local and existing run routing, and fail closed when Fleet is unavailable.


## Acceptance

- Omitted placement follows the operator’s saved preference.
- The explicit local route and existing run supervision still work.
- Fleet retains checkout ownership, permissions, published revision and enrollment requirements. Failed Fleet admission never falls back to local or native capacity.
- A new plugin installation does not opt in. The controller can select or reset its preference without exposing credentials.
