## Context

Firebase projects repeatedly reach a false "configured" state: the project and
client keys exist, but Google sign-in remains disabled, a custom app domain is
not authorized, or the first browser-based Google authorization has never run.
The result looks like an application bug rather than a provisioning gap.

## Approach

Add a Firebase Auth setup/check command that manages the Google-provider
configuration as code, uses the existing Google CLI session, opens the
Firebase browser flow only when interactive authorization or console recovery
is needed, and verifies both the provider and authorized domains afterwards.

## Acceptance

- `morpheus firebase auth setup` writes/reuses `firebase.json`, deploys Google
  provider configuration, repairs authorized domains, and reports a verified
  result.
- A deterministic `check` command fails closed when either the provider or a
  requested domain is absent.
- Onboarding, architecture, and agent instructions make the one command part
  of Firebase provisioning rather than a rediscovered manual step.
