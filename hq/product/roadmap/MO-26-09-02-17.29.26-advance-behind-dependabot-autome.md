## Context

Lakina's first live sweep correctly enabled auto-merge on three approved PRs, but every head was
behind strict `main`. GitHub retains the auto-merge request without advancing the branch, so no PR
can satisfy the up-to-date required-check rule and the queue stalls indefinitely.

## Approach

After revalidating and enabling auto-merge, request GitHub's guarded branch update only when the
current merge state is `BEHIND`, binding the request to the exact head SHA already inspected. The
new CI completion retriggers the per-PR maintainer, allowing simultaneous updates to converge as
each preceding dependency PR moves `main`.
