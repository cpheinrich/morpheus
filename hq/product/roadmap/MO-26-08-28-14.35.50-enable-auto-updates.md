## Context

Morpheus is installed as a safe standalone copy, so collaborators can drift behind reviewed
`main`. Asking each person to remember a repair command makes the operating model depend on memory.
At the same time, a repository must not silently install executable Git hooks: Git deliberately
does not activate hooks delivered by a pull, and existing project hooks such as Git LFS must survive.

## Approach

Add a one-time, device-level yes/no preference. A yes installs marked `post-merge` and
`post-rewrite` blocks across the local project registry and makes later registered projects inherit
the choice. Each hook checks the installed commit, updates from a disposable canonical clone only
when verifiably stale, serialises concurrent checks, and fails open when offline or unsuccessful.
The session brief and checked-in project instructions provide the unavoidable first-pull bridge by
asking for consent and carrying out the answer; disable removes only Morpheus's marked blocks.
