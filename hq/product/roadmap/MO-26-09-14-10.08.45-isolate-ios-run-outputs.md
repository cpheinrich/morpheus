## Context

Issue #240 reproduces a canceled process recreating shared Tests.xcresult after the next job cleaned it. Xcode then exits 64 before any test runs.

## Approach

Allocate unique results, logs and screenshots per invocation; preserve stable SourcePackages/DerivedData caches. Route artifact consumers through preparation outputs and skip them if preparation failed. Execute the actual preparation script with late writes, reruns and same-attempt calls, then run repository validation and independent review.
