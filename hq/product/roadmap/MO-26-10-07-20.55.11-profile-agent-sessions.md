## Context

Optimising the Morpheus workflow needs to know where agent time and tokens actually go — session
ceremony, checks, CI waits, review, subagents — across every project and both agent runtimes.
Both runtimes already write complete local transcripts with timestamps, model, effort, usage and
every tool call, so the data exists; nothing reads it. Agent self-reporting would cost tokens in
every session and measure belief rather than behaviour, and network telemetry is unnecessary.

## Approach

A read-only `morpheus profile` command in `src/profile/`:

- `extract [--since] [--repo] [--out]` streams `~/.claude/projects/**` (subagent transcripts
  attributed to their parent) and `~/.codex/sessions/**` into JSONL `session` and `span` rows.
- `report [--since] [--repo] [--json]` summarises time and tokens by phase, repository, role and
  model × effort, first-turn context p50/p90, slowest and most-repeated commands, subagent share.
- Phases come from an ordered, tested rule table; active time caps idle gaps at five minutes unless
  a running tool call covers them; unparseable lines are issues, never exceptions.
