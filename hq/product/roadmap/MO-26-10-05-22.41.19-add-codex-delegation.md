## Context

The `codex-claude` bridge only let a Codex task hand work to Claude. Chris also works from
Claude Code sessions and wants the same budget-aware handoff the other way, and wants
delegation to begin once the coordinating agent has used half its subscription allowance
rather than at 30% remaining.

## Approach

Extend the same package rather than fork it: one service, store, guardian and settings file
serve both directions. Add a Claude Code plugin (skill, `codex_*` MCP tools, hooks) that drives
`codex exec --json` under the existing guardian lease. Read Claude's allowance from the status
line, the only surface Claude Code exposes it on, through a chaining recorder. Map Claude
permission modes onto Codex sandboxes without widening, refuse API-key auth, and mark workers
so neither side delegates back. Raise the shared default threshold to 50%.

## Acceptance

- Fresh settings use 50%; either coordinator delegates below 50% remaining, not at 50%.
- A Claude session can inspect, start, wait on, resume and stop Codex work with persisted
  Codex session resume per working directory.
- Missing or stale Claude allowance never triggers automatic delegation.
- Permission mapping never widens; unknown modes refuse. API-key Codex auth refuses.
- Delegated workers cannot delegate back.
- Verified live on this host: real Claude → real Codex handoff, real status-line recording.
