## Context

Projects are updated by hand while Morpheus is in flight, which is correct — building `upgrade`
against a moving target means the tooling churns as fast as the thing it upgrades. But
hand-updates drift silently: Evo lacked `.agent/` and `hq/inbox/` for a week and nobody noticed
until a question happened to surface it.

**`doctor` is the cheap half of `upgrade`.** Reporting what is missing needs no knowledge of how
to fix it, no templating, and no merge strategy — so it stays useful while conventions are still
moving, which is exactly when `upgrade` would be a liability.

## Approach

```sh
morpheus doctor            # this project
morpheus doctor --all      # every project in the registry
```

Checks, all read-only:

| Check | Why |
|---|---|
| Expected directories for the declared `kind` | Catches the Evo gap |
| `morpheus.json` parses and matches schema | |
| Roadmap, goals, requests validate | Already exists as `pm validate` |
| Inbox validates | Already exists as `inbox validate` |
| Generated indexes are current | Already exists as `pm index --check` |
| Kit version vs latest | Surfaces lag without forcing an upgrade |
| Declared secrets resolve in every scope | Fails before deploy, not at runtime |
| `.mcp.json` references resolve | |

Exit non-zero on anything actionable; **never write.** Anything it cannot fix, it names.

## Explicitly not in scope

`morpheus upgrade` — applying template changes to an existing project. Deferred until conventions
settle. The narrower `morpheus add <template>` handles bolting on a *new* surface and is the only
mutation worth building before then.

**Trigger to build `add`:** the third time the same thing is bolted on by hand.

## Shipped

`morpheus doctor` and `morpheus doctor --all`. Read-only, exits non-zero on errors, never writes.

Checks the manifest parses, the prefix exists, expected directories for the declared `kind` are
present, the registry agrees with the manifest, every id uses the project prefix, and roadmap and
inbox files validate.

**It found real drift on its first run**: Evo missing `hq/ops/`. It also found a bug in itself —
it flagged Evo's missing `hq/finance/`, which is *correct* to be absent because Evo inherits
finance from Darwin. `inherits` is now respected, and that is the shape of check worth having:
one that is wrong in a way you can see.
