## Context

Evo #291 stalled on a runbook paragraph. Its reviewer conditionally cleared a fix and named the
source paths; the author's fix commit carried those paths plus the prose explaining the fix. Only a
reviewer may widen a condition, the commit was pushed so splitting it needed a force-push, and after
`covered` only the worklog may change — so a reviewed, correct change needed a human decision spent
on documentation. Every substantive turn on that PR was earned, so the cap itself was not the
problem; the missing piece was a cheap, bounded way to finish approved work.

## Approach

One automatic finalization-only turn per pull request beyond the cap: same reviewer, five minutes,
`finalization: { paths, evidence, attestation }` with a `scopeReason`. Last word, `cleared` only,
cannot resolve a substantive finding, and the attested paths are checked against the commits it
covers so it cannot approve implementation. Normative policy files are refused outright — no blanket
documentation exemption. Reviewers are told to name related docs and generated files in
`condition.paths` so this stays a backstop. `review prepare` also prints the local command that runs
CI's own schema and checker, to stop record-authoring round trips.
