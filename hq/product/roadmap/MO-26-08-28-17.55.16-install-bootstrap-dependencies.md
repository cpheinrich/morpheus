## Context

The post-merge clean-device test for MO-26-08-28-17.31.22 reached the disposable clone, then Node
failed before command dispatch because the committed CLI imports `gray-matter` and the fresh clone
has no `node_modules`. Unit tests used a fake Node process and could not expose module resolution.

## Approach

Install the clone's reviewed lockfile before invoking its committed CLI, assert that ordering in the
pre-`self` harness, then repeat the isolated real bootstrap with a temporary home, npm prefix,
registry and auto-update configuration.
