## Context

The two-host artifact/decision pilot in MO-26-10-22-23.16.58 is accepted. Chris approved
phase 2 with explicit Morpheus/Paperclip linkage: one Git roadmap parent to many execution
jobs, with Git retaining delivery authority. This first increment implements that boundary
and validates two read-only inspection jobs over an exact committed source snapshot.

The original broader consumer/host/recovery acceptance remains intact in
[MO-26-10-23-19.45.05](MO-26-10-23-19.45.05-qualify-paperclip-consumers.md). This split
separates delivery increments; it does not waive any original requirement or enable consumer
source authoring, production work, new accounts, additional hosts or remote provider inference.

## Approach

Use a thin opt-in operator bridge with the existing PM parser and native Git/JSON/HTTP.
Freeze repository, claimed branch, source SHA, acceptance and selected task references.
Persist operation identity before POST, exact-read the resulting issue, and reconcile committed
operator-verified evidence through this reviewed branch. Paperclip retains live job/run status;
Morpheus retains claim, independent review, CI and merge. No second scheduler is introduced.

## Acceptance

- Synthetic boundary tests establish one-to-many identity, committed source/acceptance refs,
  unknown-outcome no-repost behavior, exact issue readback and verified evidence ingestion
  without closing the parent item or bypassing protected delivery.
- The existing controller preserves its company/history and dashboard access while using
  upstream authenticated/private deployment with a native local owner. Anonymous API access
  is denied, operator board access works, and actual bridge/worker scopes are probed rather
  than assumed. Any broader worker authority is explicitly constrained and recorded.
- Two real read-only snapshot jobs share this roadmap and one full committed source SHA,
  have distinct operation/issue/nonces/artifacts, and produce independently checked evidence
  under `scripts/paperclip-bridge/snapshot-acceptance.md`. Only the controller performs API
  writes; model inference uses Chris's controller login within the existing budget.
- Source, linkage and sanitized evidence pass normal independent review and protected CI/merge.
  Remaining per-host protected delivery, setup, interruption and simulator/CI qualification is
  tracked by the linked follow-up before any broader capability is claimed.
