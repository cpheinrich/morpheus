## Context

A live workspace-write Claude Fleet run failed at startup when Claude Code tried to create its own temporary directory outside the task sandbox. The first dual-provider release is available through the qualification endpoint while this route is repaired.

## Approach

Point Claude Code's internal temporary files at the private temporary directory already used by the restricted worker. Exercise the actual macOS sandbox and verify the signed Claude Code runtime before enabling the route.

## Acceptance

- Claude Code starts and returns launch, result, artifact, and cleanup receipts on the restricted Fleet route.
- The existing writable paths, protected Git metadata, and gateway-only network policy retain their current boundaries.
