## Context

People repeatedly encounter pending Codex hooks when a Morpheus project adds or changes a hook. Give them a one-shot command they can ask an agent to run in that project.

## Approach

Use Codex’s hook listing and versioned config write to approve the hashes it reports for the current Git project’s root hook files. The command requires explicit invocation, preserves disabled hooks and unrelated approvals, and verifies the result. From a linked worktree, use the main checkout.
