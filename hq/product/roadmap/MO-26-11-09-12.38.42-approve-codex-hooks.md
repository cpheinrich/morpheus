## Context

People repeatedly encounter pending Codex hooks when a Morpheus project adds or changes a hook. Give them a one-shot command they can ask an agent to run in that project.

## Approach

Use Codex’s hook listing and a validated config update to approve the hashes it reports for the current Morpheus project’s committed root hook files. The command requires explicit invocation, preserves disabled hooks and unrelated approvals, and verifies the result. From a linked worktree, use the main checkout.
