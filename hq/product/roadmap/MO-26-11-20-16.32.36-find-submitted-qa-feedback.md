## Context

The shared comment QA skill sent agents to the desktop preview inbox for feedback already submitted on a live website or inside an iOS app. Those submissions live in Firestore.

## Approach

Route submitted feedback to Firestore first in both skill copies, their scaffold template, and the CLI guide. Use the configured site or build environment to select the Firebase project. Use the checkout inbox directly for explicitly local overlay submissions and as a fallback when the source is unclear and a local send is plausible. Keep lookup private and read-only.
