## Context

The CD V2 dispatcher uses an immutable `morpheus-cd-control-<sha>` tag because GitHub
rejects a raw commit SHA for workflow_dispatch. The shared upload script still permits
only main, so it refuses every otherwise qualified V2 upload before archiving.

## Approach

Keep the legacy main path. Permit only the existing CD control-tag contract bound to an
exact control SHA and the actual workflow SHA, with complete durable identity, exact source,
both trusted hooks, reserved build number, and controller-owned distribution. Test the real
script through the guard into a stub package-resolution command, with no Apple upload.
