## Context

The complexity runbook and scaffold tell agents to run `morpheus complexity check` and act on its
findings, but the tested behaviour-preserving refactoring prompt (v1.5, piloted on Evo's baseline
refactor) lives only in Evo. Every other project's agent refactors a finding without it. Its step 13
also asks for mechanical before/after CCN, cognitive and NLOC for the complete changed family, while
`check --json` emits findings only, so unflagged helpers and NLOC are invisible.

## Approach

- Ship the generic prompt as `src/complexity/refactoring-prompt.md`, copied into `dist/` by
  `pnpm compile`, printed by `morpheus complexity prompt`. Private provenance removed.
- Add `files` (every measured function row plus `targeted`) to the `--json` ran report; text, CI,
  packet and exit codes unchanged.
- AGENTS.md, the scaffold template, the complexity runbook and architecture §7.12a say to use the
  prompt for findings and to check and hand-inspect each changed family before handoff.
