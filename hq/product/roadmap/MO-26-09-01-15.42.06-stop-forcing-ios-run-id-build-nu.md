## Context

The reusable nightly workflow forced GitHub's globally unique run ID into `CFBundleVersion`.
That avoided collisions but produced eleven-digit TestFlight build numbers and prevented a caller
from allocating from App Store Connect's actual version-specific sequence.

## Approach

Stop setting `BUILD_NUMBER` in the shared upload job. Forward the caller's App Store Connect app id
and beta-group ids, install the existing `asccli` release dependency before credentials are exposed,
and make the caller-owned upload script responsible for build-number allocation and distribution.
