## Context

Chris accepted live Paperclip conversations with immutable, versioned Markdown at
wrap-up. The existing operator exporter preserves canonical JSON only, and Git
itself does not prevent rewriting those records.

## Approach

Derive a deterministic safe Markdown view from an existing verified canonical JSON
snapshot, retaining source identity and the honest non-atomic operator limitation.
Add a bounded exact-commit Git object validator and narrow CI workflow preserving
old records/blobs while validating new JSON, views and blobs. Keep acquisition,
provider actions, consumer migration and PM completion outside this prototype.
