## Context

An unbound reviewer cannot read new roadmap and worklog records in a sibling task worktree through the launch-scoped MCP. See issue #691.

## Approach

Add an optional same-repository worktree target to all five context tools. Validate canonical Git identity and registration, preserve Factory pins and session bindings, and attribute hook evidence to the validated source.

## Acceptance

- Read and search a target-only record through the launch-checkout MCP, without binding the reviewer.
- Overview, coverage and relationships use the same target.
- Reject foreign, relative, missing, unregistered and pinned-outside targets.
- Claude and Codex evidence verifies the target source; altered or unauthorized excerpts get no credit.
