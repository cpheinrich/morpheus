## Context

The full native Evo CI run revealed that Xcode parallel workers live in the private testing device set. The default simctl inventory excludes them; the first cleanup fix reclaimed only the base device.

## Approach

Inventory both default and testing device sets, preserving the selector for shutdown/delete. Keep exact per-job ownership and attempt the second set even when the first fails. Verify on the runner account with active unrelated workers.
