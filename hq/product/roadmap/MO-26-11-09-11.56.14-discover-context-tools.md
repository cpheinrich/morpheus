## Context

A user discovered the installed context MCP was absent from their live Codex tool catalog. A personal setup fixed one chat but left other users, clients and execution hosts undiscoverable.

## Approach

Use explicit project setup and existing session startup: portable client entries, proactive context guidance, preservation of authored settings and honest remote/mobile fallback boundaries. No new service, dependency, daemon or private-data publication.

## Acceptance

- New and existing projects get portable Codex, Claude Code and Cursor server setup.
- Startup outside the pilot directs live discovery and immediate CLI fallback.
- Existing settings, disabled/custom servers, comments and symlinks are preserved; check mode is read-only.
- Documentation distinguishes device execution, phone remote control, Claude Desktop and standalone cloud connectors.
- Validate actual MCP discovery/search on both authorized Macs separately from project rollout and account pairing.
