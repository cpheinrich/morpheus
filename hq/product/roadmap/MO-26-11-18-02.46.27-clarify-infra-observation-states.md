## Context

Darwin’s deployment dashboard now distinguishes expired, missing and unclassified observations. Lakina’s Infra dashboard follows the same display contract. The shared runbook described these states with one label.

## Approach

Document the three deployment cases and their evidence and link requirements. The shared helper continues to normalize expired live states to unknown so consumers can apply the right copy.

Acceptance: the runbook describes the dashboard labels without changing the shared API, reporter schema or delivery workflows.
