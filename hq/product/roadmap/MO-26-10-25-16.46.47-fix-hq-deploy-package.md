## Context

The reviewed HQ runtime failed consumer Cloud Build before activation because its isolated pnpm
package lacked explicit install-script policy and inherited its development tools from the repo.

## Approach

Pin the existing compiler/types locally, deny installation scripts in the standalone pnpm11
policy, and keep precompiled Google uploads from invoking the TypeScript build again. Verify clean
development and production directories plus compiled callable definition analysis, and ship through
independent review/CI. Parent owns real cloud retry and consumer acceptance.
