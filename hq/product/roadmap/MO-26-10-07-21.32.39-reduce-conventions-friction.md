## Context

1,298 failed `pr / conventions` logs across Morpheus, Evo, Lakina and Kairos (2026-08-23..10-07).
About 60% were the missing `agent-reviewed` label on a PR whose review simply was not finished yet
(403 with the current wording, 380 with the pre-#296 wording "add agent-reviewed only after
completing the independent review" — the same rule). Red conventions became normal: 60–71% of
Evo's runs failed. About 250 more were review-record format and coverage failures that CI was the
first thing to report, and 16 were a raw `Command failed: git show <sha>:morpheus.json`.

## Approach

- **Pending, not failed, on a draft.** A draft without the label reports a warning. GitHub refuses
  to merge a draft, and every `pr-check.yml` caller re-runs on `ready_for_review` the way it re-runs
  on `unlabeled`, so a ready PR without the label still fails and merge still needs a green run with
  the label and a valid record. A draft carrying the label is validated in full.
- **Open with the label.** The documented flow becomes: record, `morpheus review validate`, then
  `gh pr create --label agent-reviewed`; open as a draft if the PR must exist earlier.
- **`morpheus review validate`** calls `verifyReviewRecord`, the same function the CI gate calls
  once the label and line are present, against committed `HEAD`. It finds the branch's record when
  not named and checks a PR body's `review-record:` line when given one.
- **Missing PR head.** `pr-check.yml` fetches `refs/pull/N/head` when the checkout does not hold the
  head; `committedConfig` names a missing commit, defaults an absent manifest to review-required, and
  ancestry failures name the pair instead of printing a raw `git merge-base` failure.

## Acceptance

- A draft PR without `agent-reviewed` shows `pr / conventions` green with a pending warning; marking
  it ready without the label turns it red.
- `morpheus review validate` refuses every record failure `check pr` refuses, with the same message.
- No conventions failure reads `Command failed: git show <sha>:morpheus.json`.
