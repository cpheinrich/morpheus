## Context

Make it visible when gstack participates in an opted-in session.

## Approach

Label lookup results as suggestions and distinguish opt-in from actual execution.
Tell the agent to announce use or explain a skip at each applicable handoff and
report the result when returning to Morpheus.

## Acceptance

- Plain lookup output distinguishes opt-in, availability, and fallback.
- The session guide requires a visible update before use, on a skip, and after the skill returns.
- JSON consumers retain the existing response format.
