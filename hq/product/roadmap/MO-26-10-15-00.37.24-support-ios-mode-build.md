## Context

Evo has separate staging and production simulator configurations. The shared
preview always used the one top-level build, app path and bundle ID, so a
production mode still installed or launched staging. This was reported in
Morpheus #388 after Evo's production QA needed a temporary config replacement.

## Approach

Let a mode override the three identity fields together, with the build
command selecting its Xcode configuration. Validate the built app's embedded
bundle ID before installation, including for `--no-build`. Persist and
report the launched mode and bundle for status and stop. Keep the simulator,
lease and overlay shared.
