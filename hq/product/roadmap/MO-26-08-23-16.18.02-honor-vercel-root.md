## Context

The second live Evo call built successfully and then attempted to deploy from
`apps/web/apps/web`. Vercel had already applied the project's `apps/web` Root Directory, while the
workflow also started the CLI inside `apps/web`.

## Approach

Run Vercel from repository root by default so its project setting is applied exactly once. Keep the
package-manager manifest as a separate input because package layout and Vercel Root Directory are
independent concerns.
