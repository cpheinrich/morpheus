## Context

During Evo comment QA on 2026-10-04 Chris lost a half-written comment when the overlay page
reloaded (the agent had restarted the overlay server and re-navigated the Browser pane). Pins
and the draft lived only in page memory. Chris's rule: comments persist for the whole session,
regardless of simulator or overlay restarts, until the batch is sent or the tab is closed.

## Approach

The page mirrors its unsent state (pins, the next pin number, the focused pin and the draft in
the text box) into `sessionStorage` on every change, keyed by project and preview URL, and
restores it on load with a status line saying how many pins came back. A successful Send clears
it; closing the tab clears it by sessionStorage's own lifetime. No server change._
