## Context

Morpheus Security created separate private incident repositories for malware findings. The affected
repository already owns the dependency, response work, permissions, and durable project record, so
the extra repository fragments incident history without adding useful isolation.

## Approach

Remove Morpheus's external incident-repository override after the shared engine files `MAL-*`
issues directly in the affected repository. Preserve the existing deterministic remediation and
protected-check gates.
