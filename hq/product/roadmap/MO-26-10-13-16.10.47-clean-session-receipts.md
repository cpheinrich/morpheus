## Context

The cleanup command from #390 refuses a normal completed task checkout because
`morpheus context refresh` writes an ignored `local/sessions/<worktree-hash>.json`.
Most merged Evo worktrees contain this generated receipt. The cleanup safety rule
must protect user data while permitting its own generated receipt to be removed.

## Approach

Recognize only the expected session receipt path with a valid lease naming that
exact worktree, and only when `local/` contains no other entries. Keep all PR,
Git, session binding and open-process checks. Test successful cleanup and refusal
of unrelated or mismatched local files against real Git worktrees.
