## Context

Chris asked to fix the pipeline without emailing Anthropic and questioned the need for Claude in GitHub Actions. Under the existing CTO authority, the coordinating agent selected native workers after the hosted Claude setup-token could not provide required fresh subscription quota windows. No Anthropic support message was authorized or sent. The expedited first Evo staging build has already reached both tester audiences; this task owns current host preparation and empirical recovery, without claiming the full eight-delivery campaign is complete. The old hosted-provider admission item remains historical blocked work, rather than evidence of successful hosted admission.

## Approach

Use existing authenticated native Codex workers on the two Macs, with GitHub retaining the durable queue, fenced leases and CI. A separately owned core task makes hosted repair optional and keys local resume sessions by host. A separately owned Evo rollout pins that runtime, disables hosted repair and applies an exact lossless configuration migration together with explicit external tester groups. This task prepares immutable host assets, checks each actual native CLI ABI and fresh allowance, obtains independent operational review, then verifies wakeups and real recovery with one Mac unavailable. Preserve the ordinary-intent holds, original failed-source lineage, all budget/reservation history and external-review-independent internal receipts.

## Acceptance

- Both exact native worker installations pass actual login, quota, connector-disabled ABI and least-privilege credential checks; no credential-store copying or paid fallback.
- Reviewed current runtime, consumer control and normalized configuration match every executing host; historical runtimes remain preserved.
- Only explicitly reviewed, journaled one-shot activation and migration operations execute; legacy writers stay fenced.
- GitHub and native wakeups are observed, and a real durable repair continues on the independent Mac while the first worker is unavailable. Model/session claims or a synthetic ABI probe alone do not satisfy recovery.
- Record actual resulting evidence and limitations. Eight full native/TestFlight deliveries and the subsequent CTO skill remain separate campaign acceptance. No App Store production release or external messaging.
