# CD V2 evidence handling

The detailed operational RCA is retained in the private consumer repository and
private task evidence. It includes historical worklogs, run/job logs, provider
receipts and conversation provenance, and is intentionally not published here.

The public [design](cd-pipeline-v2.md) contains reusable requirements and protocols.
The [research](cd-pipeline-v2-research.md) cites public primary sources. The
[validation report](cd-pipeline-v2-validation.md) distinguishes real Git/process
experiments from protocol models and later production qualification.

Independent design review includes the private evidence through authorized local
access. Public documentation never needs private message bodies or incident
narratives to specify the platform's delivery invariants.
